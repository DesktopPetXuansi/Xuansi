# 公开网站体验

2026-10-19，现行设计遵循根 [DESIGN.md](../../DESIGN.md)。用户明确要求先调研同类桌宠官网，再修改整体公开体验。本页记录依据、职责与维护约定；检查结果和交付边界见 [验收](验收/公开网站体验-2026-10-19.md)。

## 调研与判断

检索日期为2026-10-19，使用官方或作者来源。读取了页面及链接，未安装这些产品，也没有转化率、使用频率或用户测试数据；“值得借鉴”的部分是结合本项目的设计判断。

| 官方来源 | 页面可见事实 | 本项目采用的方向 |
| --- | --- | --- |
| [Desktop Mate官网](https://www.infiniteloop.co.jp/desktopmate/) | 先介绍角色互动，再提供安装指南、下载和按图像展示的角色；问答回答启动、显示、声音、卡顿等问题。 | 首先讲用途、展示真实形象、给下载；帮助围绕实际问题。 |
| [Desktop Mate安装指南](https://www.infiniteloop.co.jp/desktopmate/install-manual/) | 分步说明安装、启动、退出、菜单和换角色。 | 新手指南一直讲到能发出第一句话、知道如何退出。 |
| [VPet官方Steam](https://store.steampowered.com/app/1920960/VPet/?l=schinese) | 互动与免费开始入口靠前，手册、更新、讨论、创意工坊各有用途。 | 下载、选形象、帮助分开，开发资料不占普通用户主导航。 |
| [Desktop Goose作者页](https://samperson.itch.io/desktop-goose) | 用抢鼠标、脚印、便条等具体行为介绍体验，按平台展示下载。 | 介绍使用具体行为，下载直接标明平台；不照搬旧日志与混合推广。 |
| [Bongo Cat官方Steam](https://store.steampowered.com/app/3419430/Bongo_Cat/?l=english) | 清楚说明键盘操作与猫拍打任务栏的可见反馈，开始与附加内容分开。 | 用用户认识的操作和反馈讲功能，不照搬掉落、交易或付费玩法。 |

同类官网也有内容漂移：Desktop Mate首页与旧安装指南的平台、语音说明不一致；Desktop Goose保留较早年份的更新文字。因此只借鉴信息结构，设备条件以本项目现行安装器与发行来源为准。

本轮核对 [官方0.7.1发行](https://github.com/DesktopPetXuansi/Xuansi/releases/tag/v0.7.1)、安装器及[安装与发布](../发布与安装/安装与发布.md)：最低Windows10 1809 x64，安装目录可选；在线AI不要求NVIDIA或D盘，但需要自己的API密钥、网络和服务额度。本机模型另有硬件与下载要求。网站原来的0.5.6/0.6.0、强制D盘与CUDA说明已经过时。

## 普通用户路径

| 页面 | 目的与下一步 |
| --- | --- |
| `/` | 看懂桌宠用途，下载客户端或挑选形象；按安装、选择AI、开始聊天三步继续。 |
| `/resources` | 先看到自带玄司和使用方法，再浏览真实已发布资源。空库不冒充有资源，仍可导入自己的图片或模型。 |
| `/resources/[id]` | 看预览、作者和许可，下载可用版本；明确解压、本地导入、预览、点击使用。动作/表情说明配套要求。 |
| `/download` | 单一官方正式版主下载，解释系统条件、在线与本机方式、升级、安装帮助；校验信息折叠。 |
| `/docs` | 按正在做的事选择帮助，不要求先理解工程模块。 |
| `/docs/getting-started` | 下载、选择AI、启动与退出。 |
| `/docs/appearance` | 本地导入、在线挑选、资源包解压、预览与使用。 |
| `/docs/chat` | AI设置、文字、语音、截图和记忆授权。 |
| `/docs/account` | 网站登录用途、下载/收藏、浏览器授权、历史同步与本机记录边界。 |
| `/docs/troubleshooting` | 安装、无回复、导入预览、声音问题及反馈方式。 |
| `/faq` | 帮助内的具体问答，可直接进入相应步骤；保留旧地址。 |

主导航收敛为首页、挑选形象、使用帮助、下载客户端。产品概览、更新记录与法律页保持原地址可达；页脚按使用、项目与反馈、法律三组排列。个人空间和管理员权限保持既有边界。

## 模块与维护

- 帮助由 [help](../../web/frontend/src/features/help)维护：任务数据、问答、展示与局部样式分开；五个主题构建时生成，未知主题404。原生`details`支持键盘，不增加帮助页客户端脚本。
- [client-release.ts](../../web/frontend/src/lib/client-release.ts)统一公开版本、日期与链接；[releases.tsx](../../web/frontend/src/features/releases.tsx)只在更新历史挂载平台查询。以后发行时须更新此处并核对真实GitHub资产，不让多个页面分别写版本。
- 公开资源与个人管理复用查询和事件；真实加载、失败、空库与筛选无结果分开。标签、入口文件、摘要和依赖按需展开；兼容风险、作者与许可继续可见。管理模式保留全部版本和设置当前版本操作。
- 网站下载只保存文件，不直接控制桌宠。软件内“在线挑选”可下载并预览；本地导入无需上传。不能将网页收藏描述为自动换装。
- 在线AI内容发送与网站云存储分别说明。形象历史同步是尚未纳入公开0.7.1的新客户端能力；AI配置历史、聊天、截图、录音与密钥不在网站同步范围内。

未增加依赖、商品交易、社区数据或网页Live2D运行时。保留现有品牌素材、颜色、账号表单、回程安全与页脚贴底外壳。
