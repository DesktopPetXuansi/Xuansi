# 玄司久置拔刀姿态

文档同步：2026-10-07。当前源码与历史版本入口见 [文档索引](../../../文档索引.md)。

这组透明 PNG 用于默认 Live2D 玄司的单次久置待机动作。`reach.png` 抬手够刀柄，`grip.png` 握住刀柄，`draw-half.png` 半拔，`drawn.png` 展示完整拔出的长刀；播放时按相反顺序收刀。

现有 PSD 的身体层合并了双臂。运行时使用全身透明姿态，可以避免单独叠加手臂时留下原手臂重影。姿态显示时清空 GL 缓冲，只显示姿态帧，暂停底层 Live2D 参数更新和绘制；动作结束或用户有键鼠输入后淡出姿态并恢复模型。默认尺寸下四帧缓存约 0.29 MiB，素材只在应用初始化或桌宠尺寸更改时读取和缩放。

2026-10-07 更正：原说明“Live2D 模型本身仍在下层正常更新”对应早期实现，已按当前 [Avatar 绘制源码](../../../pet/avatar.py) 更正；暂停底层绘制的修复已包含在 0.5.0 及后续版本。此次默认形象预览不加载拔刀姿态，不会因预览窗口久置自动播放此动作，见 [预览修复验收](../../../形象预览Live2D修复验收.md)。
