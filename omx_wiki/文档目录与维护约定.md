# 文档目录与维护约定

整理日期：2026-10-15。用户要求所有项目文档按模块分类，统一放到一个文件夹；本次已将 50 份分散文档归档至 `omx_wiki/`。

## 目录规则

完整导航由 [项目文档总览](README.md) 维护。普通文档按以下九个模块分类：

| 目录 | 内容 |
| --- | --- |
| `项目/` | 项目介绍、架构、开发贡献、更新、许可来源和历史规格 |
| `客户端/` | 使用、配置、故障排查、官网上传、任务和验收 |
| `对话与记忆/` | 模型控制、记忆决策及相关验收 |
| `语音/` | 流式与实时语音、朗读及声音回避验收 |
| `屏幕观察/` | 观察相关验收 |
| `Live2D与形象/` | 制作规格、素材说明和形象验收 |
| `官网/` | 规划、设计、接口约定、本地运行、部署、任务与验收 |
| `发布与安装/` | 安装指南、安装器须知和历次发布验收 |
| `文档维护/` | 历次文档核对、修复清单和验收 |

任务和验收放在对应模块的 `任务/`、`验收/` 子目录。Wiki 原生速记页留在统一目录根部，由技能继续维护其 frontmatter、交叉链接、`index.md` 和 `log.md`；速记页也按业务模块列入总览。原生 Wiki 的关键词检索只检索其直接维护的速记页，完整模块文档从总览或 `rg omx_wiki` 查找。

仓库根 `README.md` 只作为入口。`AGENTS.md` 保持作用域位置；LICENSE/NOTICE、素材许可证、依赖锁文件、OpenAPI、Schema、生成类型、测试夹具和生产配置保留各自功能位置，不作为普通文档搬走。

## 迁移与维护

迁移前已逐项验证源和目标位于当前项目，保存原文并检查原有本地链接。原文、文件和锚点间引用按新路径重算；素材 README 增加原素材目录说明，部署说明保留可从仓库根执行的路径。仅文档移动，不改变素材、模型、工程或数据库位置。

安装器 `InfoBeforeFile` 已改用 `omx_wiki/发布与安装/安装须知.txt`。`NOTICE`、`assets/xuansi/LICENSE` 和便携依赖脚本的说明路径已同步，许可条款未改变。

新增普通说明时更新总览；移动文档时同时检查 Markdown/HTML 链接、锚点、Wiki sources、源码/脚本中的路径和安装器输入。历史验收保留原日期、测试数量、耗时、失败和发行边界，当前实现与后续复验单独记录。

原 `docs/`、`web/docs/`、`web/tasks/` 仅是旧文档位置；后续不要在这些位置新增普通说明。构建产物、第三方依赖文档、运行报告与 `.omx/` 工作流状态不纳入归档。

相关交付与环境快照：[[客户端-live2d-直接上传验收-2026-10-15]]、[[本地运行与邮件测试约定]]。
