# 玄司久置拔刀姿态

这组透明 PNG 用于默认 Live2D 玄司的单次久置待机动作。`reach.png` 抬手够刀柄，`grip.png` 握住刀柄，`draw-half.png` 半拔，`drawn.png` 展示完整拔出的长刀；播放时按相反顺序收刀。

现有 PSD 的身体层合并了双臂。运行时临时叠加全身透明姿态，可以避免单独叠加手臂时留下原手臂重影。Live2D 模型本身仍在下层正常更新；动作结束或用户有键鼠输入后淡回原模型。默认尺寸下四帧缓存约 0.29 MiB，素材只在应用初始化或桌宠尺寸更改时读取和缩放。

姿态图基于 `assets/xuansi/front.png` 制作，作为玄司美术素材的衍生图受 `assets/xuansi/LICENSE` 所列权利约束。源 PNG、Live2D PSD、网格和纹理均保持不变。
