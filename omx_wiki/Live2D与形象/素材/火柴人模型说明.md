# 循环挥手火柴人

素材位置：[assets/stickman/](../../../assets/stickman/)。下文“本目录”和运行、工程、预览文件均指该素材目录；仅说明文档迁移到这里。该模型当前属于本机未跟踪素材，新克隆中可能不存在；本次归档不将模型或工程纳入提交。

512 × 768 全身火柴人，黑色圆角线条和透明背景。唯一动作是右前臂绕肘关节挥手，左右极值约 25°，每个周期 2 秒；头部、身体、另一只手和双腿保持静止。

## 使用文件

- `stickman.model3.json`：Live2D 播放器加载入口。复制模型时保留本目录的相对路径。
- `stickman.moc3`：由本机 Cubism Editor 5.3.04 的模型导出器生成，目标为 SDK 5.0。
- `textures/texture_00.png`：512 × 512 透明纹理图集。
- `motions/wave.motion3.json`：唯一挥手动作，30 FPS、2 秒、首尾闭合。`Idle` 和 `Wave` 两个动作组引用同一文件。
- `source/stickman.cmo3`：可编辑 Cubism 模型工程，包含七个 ArtMesh 和一个 `ParamWave` 参数。
- `source/stickman-layers.psd`：七层原始素材；`source/layers/` 保留各层透明 PNG。
- `preview-wave.gif`：从实际 Live2D/OpenGL 画面捕获的动画预览，使用米白背景便于查看。

播放器需启用动作循环，或在动作结束时重新播放同一动作。官方 Framework 的循环设置应在运行时设置，不能仅依赖 JSON 的 `Meta.Loop`；参见 [官方动作播放说明](https://docs.live2d.com/en/cubism-sdk-manual/motion/)。本目录的独立预览脚本会在动作结束后重播 `Wave`。

## 复现与验收

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe assets\stickman\source\generate_art.py
& .\assets\stickman\source\build-model.ps1
.\.venv\Scripts\python.exe assets\stickman\source\preview.py
```

模型构建需要本机安装的 Cubism Editor 5.3.04 和 JDK。编辑器目录不同时向 `build-model.ps1` 传入 `-EditorDirectory`。制作脚本调用这一版本的本机编辑器内部类型；不是官方稳定的 SDK 建模 API，不随素材分发编辑器 JAR 或 DLL。工程保存后重新读入，再由编辑器导出真实 `.moc3`。

原生验收使用项目现有 `live2d-py` 和 PySide6，不读取桌宠配置。`verification/report.json` 记录三周期参数范围、真实网格、透明背景、全身边界、静止部件与源素材的像素一致性，以及前臂的实际变化；`verification/frame-*.png` 是实际 OpenGL 截图。

建模只使用七个四点网格、一个参数和一张图集，没有物理计算和额外特效。素材是为本次任务绘制的原创火柴人，没有修改现有玄司模型或应用配置。

格式依据：[官方嵌入数据导出说明](https://docs.live2d.com/en/cubism-editor-manual/export-moc3-motion3-files/)。
