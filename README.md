# 玄司 Xuansi · 本地 AI 桌宠

玄司是运行在 Windows 上的桌面 AI 伙伴，支持屏幕理解、文字聊天、连续语音、长期记忆和 Live2D 形象。可选本机模型或自备 API 密钥的在线服务；本机对话无需云端账号，在线调用由服务商直接计费。名字、人设、声音和形象可在软件中调整。

## 版本与发布

0.7.1 将控制中心默认尺寸收紧为720×560并记住窗口大小，统一“更换形象”流程；候选必须真实加载可用，应用失败保留原形象并恢复形象记录。继续提供安装前设备检测、可选模型目录、独立语音组件和在线服务，专业参数默认折叠。默认本机模型为 Qwen3.5-9B Q4_K_M 与匹配看图组件。实际版本及来源以安装目录 `release.json` 和 [GitHub v0.7.1](https://github.com/DesktopPetXuansi/Xuansi/releases/tag/v0.7.1) 为准，构建、安装和公开状态见 [0.7.1 发布验收](omx_wiki/发布与安装/验收/安装包0.7.1发布验收.md)。

在线记忆读取与自动观察截图分别授权、默认关闭；关闭自动截图不禁用单次附图或对话中的按需截图。4B 模型仍为实验选项，已有语义验收失败，不作为完整自动备用；CPU、其他服务商和跨设备能力仍有实测缺口。具体证据与已知限制见 [多模型实施验收](omx_wiki/客户端/验收/安装前适配与多模型-2026-10-18.md)。历史 0.6.0 的构建与发行身份见 [原发布验收](omx_wiki/归档/发布与安装/验收/安装包0.6.0发布验收.md)。

公开0.7.1的“更换形象”支持本地导入或在线挑选，预览后点击使用自动保存。2026-10-19新源码进一步支持在线/我的形象一键使用：选中后点击“使用这个形象”，自动下载或复用完整副本、检查并切换，预览可选；[任务与验收](omx_wiki/客户端/任务/形象一键使用-2026-10-19.md)。此新增尚未纳入公开安装包。资源管理与上传分享继续为页内入口，旧标签、安装包和历史验收保留。

## 已实现能力

- 屏幕理解：鼠标点击、拖拽结束、滚动和停留触发观察；整块显示器或鼠标附近两种范围，也可手动附图提问。
- 聊天与记忆：本地图文对话、近期会话上下文；由模型按需查询和保存。提示要求明确请求保存、含糊时先询问，实际理解仍可能误判；也可直接手动编辑长期记忆。
- 连续语音：手动启麦、实时转写、话段结束后生成并分段朗读。提交后暂停收音，回复处理及播放完成再恢复；不支持全双工口头插话。
- 角色动画：默认 Live2D 眨眼、视线、响度口型及发丝衣摆摆动；直接动作请求目前只开放一次眨眼。满足空闲条件后播放预制拔刀姿态。
- 形象替换：新源码在“在线挑选”或“我的形象”选中后可直接使用，独立预览可选；本地导入图片、动图或导出的Live2D运行模型后点击使用。成功自动保存，失败保留原形象，更换无需先上传；公开0.7.1的旧步骤见上节。
- 桌面控制：对话、设置、记忆、更换形象及日志集中在同一控制窗口，通过七个横向主标签切换；官网资源与上传保留在形象页的次要入口，沿用暖白和草绿配色。角色点击、托盘和快捷键打开同一窗口；顶部提供连续对话和休眠，对话页提供朗读、看屏幕、停止回复及声音回避；启动不自动开启麦克风。
- 官网资源：在控制中心连接官网账号，直接选择本地 Live2D 模型文件夹或入口文件上传，自动整理、校验与加入资源库；也支持资源下载安装及离线使用。[客户端上传说明](omx_wiki/客户端/使用指南.md#官网资源与本地上传)。

详细操作与能力边界见 [使用指南](omx_wiki/客户端/使用指南.md)，模块及调用顺序见 [项目文档](omx_wiki/项目/项目文档.md)。

## 下载与安装

从 [GitHub v0.7.1](https://github.com/DesktopPetXuansi/Xuansi/releases/tag/v0.7.1) 获取 Windows x64 在线安装包与 `SHA256SUMS.txt`。安装包内置 Python 3.13.15，无需预装 Python 或 Git。

安装器支持 **Windows 10 1809 及以上 x64**，安装前会评估系统、内存及磁盘，并允许选择模型目录。仅使用在线服务时不要求 NVIDIA 显卡、本机模型或 D 盘；本机加速按实际设备选择，CPU 路线尚未完成真实设备验收。标准 9B 权重和看图组件约 6.60 GB，语音、环境与引擎另计。首次安装需要联网，资源和临时空间以向导预检为准，资源估算不保证实际回复速度。

安装完成后从开始菜单“玄司 AI 桌宠”启动。升级前从托盘退出旧实例，选择原安装目录；记忆、人设和导入形象保留，模型与语音字段按向导选择更新，旧配置另存为 `data/settings.before-install-*.json`。程序没有自动更新或跨目录数据迁移，来源可查看安装目录的 `release.json`。

完整前提、校验、源码安装、升级保留范围及构建步骤见 [安装与发布](omx_wiki/发布与安装/安装与发布.md)。

## 从源码运行

准备 Git 和 64 位 Python 3.13，执行：

```powershell
git clone https://github.com/DesktopPetXuansi/Xuansi.git
cd Xuansi
py -3.13 --version
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
.\.venv\Scripts\pythonw.exe -m pet
```

未传安装计划时，脚本仍创建项目内 `.venv` 并下载全套本地及语音资源，包括 Kokoro；不设置开机启动。新源码默认识别旧 D 盘模型目录，其他情况使用 `%LOCALAPPDATA%/Xuansi/models`。API-only 和按选项部署通过安装计划执行，详见 [源码安装说明](omx_wiki/发布与安装/安装与发布.md#源码安装)。
