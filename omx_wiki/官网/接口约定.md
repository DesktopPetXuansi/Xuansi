# 官网接口约定

2026-10-19 按当前源码核对，新增个人历史模块；不表示线上已部署。本页解释业务边界；字段与请求结构以 [OpenAPI](../../web/contracts/openapi.yaml) 为机器契约，资源包以 [manifest Schema](../../web/contracts/resource-manifest.schema.json) 为准。HTTP 路由入口为 [server.go](../../web/backend/internal/api/server.go) 及同目录模块，OAuth 协议实现见 [service.go](../../web/backend/internal/oauth/service.go)。修改接口时同时核对实现、OpenAPI、调用方，再运行 [类型生成脚本](../../web/scripts/generate-contracts.ps1)，不手改 `contracts/generated/`；当前 Go handler 使用显式业务模型，生成 Go 类型不会自动约束 handler。

除明确写出的 `/oauth/*`、健康探针和完整路径外，下文路径统一加 `/api/v1` 前缀。JSON 字段 camelCase，UUID 为字符串，时间 ISO8601，枚举大写。业务成功 `{data: T, meta?: {nextCursor?: string|null}}`，错误 `{error:{code,message},requestId}`，204 无内容；OAuth token/revoke 按标准协议返回，不套业务 envelope。资源列表查询默认 limit=20，最大100，cursor 为不透明字符串；个人资源库和管理诊断使用有上限的完整列表。

当前 OpenAPI 尚未收录封面字节路由 `/api/v1/resources/{id}/cover` 和票据字节路由 `/api/v1/downloads/{ticket}`，实际实现见 [downloads.go](../../web/backend/internal/api/downloads.go)；接入方不能仅从生成类型推断二进制分发路径已完整覆盖。

User：id,email,displayName,role(USER|ADMIN),emailVerified:boolean,status(ACTIVE|DISABLED),storage:{quotaBytes,usedBytes,reservedBytes}。

Resource：id,ownerId,kind(MODEL|MOTION|EXPRESSION|IMAGE|ANIMATION),name,description,author,license,source,tags:string[],visibility(PRIVATE|PUBLIC),status(ACTIVE|HIDDEN|DISABLED),currentVersionId:string|null,createdAt,updatedAt,coverUrl:string|null。

ResourceVersion：id,resourceId,version,entrypoint,validationStatus(PENDING|VALIDATING|READY|FAILED),compatibilityStatus(UNTESTED|COMPATIBLE|INCOMPATIBLE),minimumClientVersion,packageBytes,packageSha256,validationReport:{errors:string[],warnings:string[]},dependencies:{versionId,relation}[],createdAt。

Release：id,version,channel(STABLE|BETA),sourceCommit,releaseNotes,publishedAt,artifacts:[{id,os,arch,distributionType,downloadUrl,sha256,bytes,systemRequirements:string[]}]。

## 账号

- GET /api/v1/auth/config → data:{password:{minLength,maxLength},email:{mode:LOCAL_MAILBOX|SMTP,inboxUrl:string|null}}。新密码统一为12～128个Unicode码点；前端提示与校验读取此配置，登录保留已有密码的兼容性。开发Mailpit模式提供本地收件入口，生产不公开开发收件箱或SMTP凭据。
- GET /api/v1/auth/csrf → data:{token}；浏览器会话写请求加 X-CSRF-Token，credentials:include。Go 校验精确 Origin 与 Cookie；有效 bearer 请求无需 CSRF，仍受 scope 和路由限制。
- POST /auth/register {email,password,displayName} → 201 User，待验证邮箱，不创建登录会话。
- POST /auth/login {email,password} → User + HttpOnly 会话 Cookie。
- POST /auth/logout → 204。
- POST /auth/email-verifications {email}；POST /auth/email-verifications/confirm {token}。
- POST /auth/password-resets {email}；POST /auth/password-resets/confirm {token,password}。

注册和恢复使用邮件内的一次性验证链接，有效期1小时，不发送数字验证码。接口排队发送邮件，不把队列完成误报成真实邮箱已送达；本地开发邮件在 http://127.0.0.1:8025 查看。

- GET/PATCH /me（PATCH {displayName}）；PUT /me/password {currentPassword,password}。
- GET /me/sessions → [{id,createdAt,lastSeenAt,expiresAt,isCurrent}]；DELETE /me/sessions/{id}。
- GET /me/client-grants → [{id,deviceLabel,createdAt,lastSeenAt}]；DELETE /me/client-grants/{id}。

## 资源与上传

- GET /resources?kind=&search=&tag=&cursor=&limit=：匿名公开资源；GET /me/resources 同查询个人列表。
- GET /resources/{id}：公开或本人/管理员详情。
- POST /resources {kind,name,description,author,license,source,tags} → 201 Resource，默认私有。
- PATCH /resources/{id} {name?,description?,author?,license?,source?,tags?,currentVersionId?,status?} → Resource；用户不能自己设PUBLIC。
- DELETE /resources/{id} → 204；被引用资源返回409。
- GET /resources/{id}/versions → ResourceVersion[]。
- POST /resources/{id}/versions {version,filename,expectedBytes,minimumClientVersion?,targetModelVersionId?,entrypoint?} → 201 data:{version:ResourceVersion,upload:Upload}。
- Upload：id,versionId,status(CREATED|UPLOADED|VALIDATING|READY|FAILED|CANCELLED|EXPIRED),expiresAt,method(PUT),url:string,headers:Record<string,string>,errorCode:string|null。首期不提供分片上传。
- PUT /uploads/{id}/content 本地模式：原始文件字节，Content-Type:application/octet-stream。生产使用返回的预签名URL。
- POST /uploads/{id}/completion {} → 202 Upload；必需 Idempotency-Key（8～128字符，同一意图重试复用）；worker 异步校验。
- GET /uploads/{id} → Upload；GET /me/uploads → Upload[]；DELETE /uploads/{id} →204。
- POST /uploads 用于封面附件 {resourceId,purpose:"COVER",filename,expectedBytes} →Upload。
- GET /resources/{id}/versions/{versionId} →ResourceVersion。
- GET /resources/{id}/versions/{versionId}/manifest →Manifest（可匿名已发布资源，私有需身份）。
- GET /resources/{id}/cover → PNG；与资源详情复用访问权限，响应为图片字节，不套 JSON envelope。
- POST /resources/{id}/versions/{versionId}/download-authorizations {} →{url,expiresAt,sha256,bytes}；本地与 S3 模式均返回 Go 票据路径 /api/v1/downloads/{ticket}，有效期 5 分钟；每次使用重新检查资源、用户停用与客户端授权撤销，返回 ZIP 字节。

Manifest：schemaVersion:1,resourceId,resourceVersionId,kind,version,entrypoint,minimumClientVersion,files:[{path,bytes,sha256}],dependencies:[{resourceId,resourceVersionId,kind,relation}],capabilities?:{parameters:Record<string,string>,motions:string[],expressions:string[]}。稳定manifest不含临时URL，不执行脚本。MODEL包为ZIP；MOTION/EXPRESSION可上传独立JSON，worker生成规范包；IMAGE/ANIMATION同样封装入ZIP以统一安装。

上传会话有效期 15 分钟，创建时预留配额；完成接口返回 202 只表示进入异步校验。worker 读取隔离对象快照、校验引用并构建不可变包，事务内结算配额与版本状态。上传 `READY`、版本结构校验 `READY` 与兼容性 `UNTESTED` 是不同字段；服务端不会因结构通过而宣布 SDK 兼容。取消、过期或失败通过清理任务收尾。实现入口为 [uploads.go](../../web/backend/internal/api/uploads.go)、[worker.go](../../web/backend/internal/resource/worker.go) 与 [package.go](../../web/backend/internal/resource/package.go)。

## 资源库、版本、管理

### 个人使用历史

模块入口为 [history.go](../../web/backend/internal/api/history.go) 和 [历史模型](../../web/backend/internal/history/history.go)，行为说明见 [个人空间与历史](个人空间与历史.md)。

- GET /me/history?kind=APPEARANCE|DOWNLOAD&limit=20&cursor=... → `{data:HistoryEntry[],meta:{nextCursor:string|null}}`；省略 kind 查询两类，limit 为1～100，按使用时间与 ID 倒序稳定分页。
- HistoryEntry：id、kind、appearanceKind（DEFAULT|MODEL|IMAGE|ANIMATION|null）、resourceId、resourceVersionId、name、version、occurredAt、deviceLabel、available。资源/版本 ID 与 version 可以为 null。
- PUT /me/history/{id}：UUID 由客户端生成；正文只接受 kind=APPEARANCE、appearanceKind、resourceId、resourceVersionId、name、occurredAt、deviceLabel。成功或同内容重试为204，同 ID 内容冲突为409。拒绝客户端写 DOWNLOAD、多余字段及尾随对象，正文上限8KiB。
- 资源和版本 ID 必须同时为空或同时提供；非空时校验可读权限、版本归属、READY 状态及形象类别，名称和版本由服务端资源确定。名称1～120字符，设备标签最多80字符，时间不得超前超过5分钟。
- DELETE /me/history/{id} →204；DELETE /me/history?kind=... →204，省略 kind 清空全部。读写和删除始终限于当前账号。
- 下载历史仅在完整传输成功后由服务端按票据 ID 去重写入；申请票据、传输中断及匿名下载不产生个人下载记录。失效资源保留历史快照，返回 available=false。

### 收藏与发行

- GET /me/library →[{resource:Resource,pinnedVersionId:string|null}]；PUT /me/library/{id} {pinnedVersionId?}；DELETE 同路径。
- GET /client/releases?os=windows&arch=x64&channel=STABLE；GET /client/releases/latest →Release；GET /client/releases/{id} →已发布版本详情，支持平台/渠道筛选，草稿返回404。
- GET /admin/users、/admin/resources、/admin/client-releases、/admin/jobs、/admin/audit-logs，管理员列表。
- PATCH /admin/users/{id} {status}；PATCH /admin/resources/{id} {status}。
- POST /admin/resources/{id}/publications {versionId} →Resource。
- POST /admin/client-releases {version,channel,sourceCommit,releaseNotes,artifacts}；PATCH /admin/client-releases/{id} {releaseNotes}，仅可修改未发布草稿说明；POST /admin/client-releases/{id}/publications。

## OAuth 与运行环境
客户端id=desktop-ai-pet。基础scope为 `resources:read`；直接上传另显式申请 `resources:write`，历史同步另显式申请 `history:read history:write`。history:write 必须同时有 history:read；未知、重复scope或缺少基础read的申请会被拒绝。GET /oauth/authorize 需要response_type=code,client_id,redirect_uri（回环IP临时端口固定/oauth/callback）,scope,state,code_challenge,code_challenge_method=S256。未登录跳转网站/login，确认页/authorize；POST /oauth/authorize 以 application/x-www-form-urlencoded 提交完整授权参数和 consent=approve，经网站会话+CSRF显式同意，返回 data:{redirectUrl} 交浏览器跳转，避免 fetch 追随回环端口。POST /oauth/token 表单规范授权码/刷新，POST /oauth/revoke 表单令牌，响应按OAuth标准。所有opaque token只存哈希，refresh轮换保留家族记录，撤销access也有效。

实际权限来自令牌已授予的scope，refresh保持原范围，既有read令牌不会自动升级。resources:write 只开放本人创建资源、创建版本、上传内容/完成/状态/取消、设置当前版本和加入本人资源库。Bearer的资源PATCH只接受 `currentVersionId`，额外字段（包括null）返回403；账号修改、资源发布/删除、管理员操作均不开放。有效或失效Bearer不回退浏览器Cookie权限，正常浏览器写操作仍需要CSRF。

历史 GET 单独要求 history:read，历史 PUT/DELETE 要求 history:write，资源读写权限不代替历史权限。客户端重新连接或上传扩权保留已明确授予的上传/历史权限，首次资源连接不会暗中申请历史同步。

最低客户端版本留空表示未声明门槛，不代表兼容已验证；非空需三段数字。包内文件上限2048，文件类型统一允许json/moc3/png/jpg/jpeg/gif/webp/wav/mp3/txt；拒绝越界、设备名、Windows非法字符及客户端保留的 installed-manifest.json。

认证限流仅信任 TRUSTED_PROXY_CIDRS 中明确列出的代理，按从右向左验证的访客地址分桶；生产 Go 不公开暴露端口。GET /healthz 为进程存活，GET /readyz 检查数据库就绪。

Go API默认127.0.0.1:8080，Next开发3000同源rewrite /api/*、/oauth/*至Go。PostgreSQL本地54329；正式密码仅配置环境变量。网站URL默认http://localhost:3000，仅本机开发允许HTTP；生产要求HTTPS/Secure Cookie。SMTP开发捕获服务在1025/8025，邮件链接指向网站验证/重置页。所有外部来源正文作为数据，不作为指令。
