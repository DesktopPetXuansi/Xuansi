# 账号页面

2026-10-19 按源码核对。页面沿用暖白与草绿、公共导航及现有账号接口；不改变邮箱验证、密码规则和后端权限。访客入口见 [个人空间与历史](个人空间与历史.md)，机器契约见 [接口约定](接口约定.md)。

## 按任务展示

| 页面 | 操作与反馈 |
| --- | --- |
| 登录 | 邮箱、密码、与输入框同宽的登录按钮；忘记密码紧邻密码标签，注册单独一行。初次访问不显示验证邮件或开发邮箱帮助。 |
| 注册 | 邮箱、昵称和设置密码，规则读取服务端配置；成功后隐藏已完成表单，显示邮件验证说明、返回登录及重发入口。 |
| 找回密码 | 仅输入注册邮箱；发送后的结果继续保持不泄露账号是否存在的通用提示，需要时显示本地邮箱帮助。 |
| 重置密码 | 使用邮件链接设置新密码；成功后隐藏表单，提供返回登录。链接本身带有站内返回目标时会保留；邮件模板目前不自动携带原目标。 |
| 邮箱验证 | 无令牌时填写邮箱以重发邮件；有令牌时显式点击确认，完成后展示结果和返回登录。 |

密码默认隐藏，切换可见性保留值且不提交表单；可用键盘操作，按钮与输入项通过 ARIA 关联。字段错误显示在相应输入项附近，服务端错误保留真实提示。输入和主要按钮至少48px高，辅助操作至少44px高；手机不会把四个不同任务的链接挤成一排。

账号页继续提供较弱的返回首页和条款入口。登录、注册及找回页面之间保留传入的站内目标；返回地址按规范化结果校验，不能借助双斜杠、反斜杠或点段跳出本站。
