# 个人空间与历史

2026-10-19 按当前源码核对。本文维护网页个人空间的模块与数据边界；客户端操作见 [形象与模型历史](../客户端/形象与模型历史.md)，接口见 [接口约定](接口约定.md)。这些新增能力尚未纳入公开 0.7.1 安装包，也不表示线上网站已部署。验证范围见 [本轮验收](验收/个人空间与历史-2026-10-19.md)。

## 入口与模块

公共资源仍可匿名浏览。登录后，主导航显示昵称与“我的桌宠”，个人空间按以下分组组织；管理员入口继续独立校验权限。

公共导航明确提供“首页”。访客、身份检查中和身份请求失败时不渲染个人侧栏；直接访问个人页会显示独立登录引导，提供登录、注册与返回首页。登录或注册页面之间切换时保留站内原路径及查询参数，登录后回到目标，退出后返回公开首页。普通账号访问后台时不显示管理菜单。实际验证见 [访客入口与登录流程](验收/访客入口与登录流程-2026-10-19.md)。

| 分组 | 页面 | 内容 |
| --- | --- | --- |
| 我的桌宠 | `/dashboard` | 昵称、最近同步的形象及设备/使用时间、最近使用、收藏入口。 |
| 我的桌宠 | `/dashboard/history` | 形象使用与下载记录两类，分别分页、单条删除或清空当前类别。 |
| 我的桌宠 | `/dashboard/library` | 手动收藏的资源及固定版本，独立于使用和下载历史。 |
| 上传管理 | `/dashboard/resources`、`/dashboard/uploads` | 我的作品与上传队列，保留原有路由及上传事务。 |
| 账号 | `/dashboard/account`、`/dashboard/sessions` | 资料、密码、浏览器会话和客户端授权。 |

“最近同步的形象”取最近一条已同步的成功使用记录，显示记录中的使用时间与设备标签；它不查询桌宠的实时状态，也不能从网页直接切换桌面形象。没有同步记录时显示真实空状态。

## 三种记录各自成立

- **形象使用**：桌宠保存选择、真实试载均成功后在本机追加；用户主动开启同步后，才上传此后新记录。预览、下载、失败和回滚不记为实际使用。
- **下载记录**：登录用户的文件传输完成后由服务端生成；申请下载票据不算成功，匿名下载不记个人历史。记录绑定原资源版本，“查看 / 重新获取”定位该版本。
- **收藏**：用户在资源详情主动收藏；可固定版本，不因使用、下载或删除历史自动改变。

资源失效或不可访问时，历史快照仍显示名称和版本，并提示无法重新获取。本机图片、动图及本地模型只同步最小记录，网站没有其文件；需要回到原设备预览选择。删除网站记录不会删除本机文件、收藏或更改当前桌宠形象。

登录、退出和切换账号统一经过会话模块：先取消旧查询、清空查询缓存，再设置新身份。个人历史和收藏不得继续显示上一账号的数据。网络错误保留错误提示，只有未授权响应转为匿名状态。

## 同步与隐私

桌宠默认仅本机记录，开启同步需要浏览器显式同意 `history:read history:write`；旧资源授权不会自动升级。同步绑定官网 URL 与用户 ID，不补传开启以前的记录，不跨站点或账号发送。关闭后停止后续发送，并使仍在等待的开启授权失效；已发出的请求可能已由服务器处理，关闭不会删除网站已有记录。

同步正文仅包含形象类别、资源及版本 ID、名称、使用时间和设备标签，不包含本机路径、模型 API 地址、凭据引用、密钥、聊天、记忆或屏幕内容。AI 模型配置历史始终留本机。
