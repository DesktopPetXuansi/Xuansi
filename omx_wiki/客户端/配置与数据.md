## 首次聊天状态（当前源码）

`data/first-chat.json` 独立保存 `{"version":1,"completed":true}`，只说明曾收到普通文字聊天的有效最终回复。它不包含对话、邮箱、API 地址、密钥、模型路径、记忆或账号信息，也不加入 `settings.json` 或 `install-plan.json`。缺失、损坏或不支持的版本按未完成显示提示，读取不会修改原文件。

文件检查和标记写入在后台完成；标记原子替换，写入失败不影响已交付文字，界面会说明下次可能再次显示引导。用户手动收起不会写成功标记。后续成功对话清除旧恢复提示，但不重复写入标记；迟到检查、旧请求结果和旧写入提示不能覆盖当前错误。

引导只读取已保存配置。模型和密钥草稿仍由 `PanelSettings → CompanionUI → Runtime.persist` 的既有事务保存，完成凭据快照确认后才重新检查；不另建凭据存储，不在启动时验证收费 API。代码及验证入口见 [首次文字聊天验收](验收/首次文字聊天-2026-10-25.md)。

## 默认值与校验范围

设置位于当前应用根目录的 `data/settings.json`，不是全局用户配置目录。未知字段忽略，缺失字段补默认值；值的 Python 类型也严格校验。JSON 无法读取、类型或校验错误时整份回退默认设置，保留原文件，不是逐项纠正损坏值。

### `ai` 配置与验证作用域

`AISettings` 与其中的 `ModelProfile` 为不可变配置。旧 JSON 缺少 `ai` 时补默认值；不支持的 schema 版本不能直接当作当前配置使用。

| `ai` 字段 | 默认值 | 含义 |
| --- | --- | --- |
| `schema_version` | 1 | 当前配置格式版本 |
| `policy` | `local_only` | `local_only` 仅本地、`local_first` 本地优先且允许在线兜底、`online_first` 优先在线 |
| `local_model` | `qwen3.5-9b` | 本地主模型档位；轻量 `qwen3.5-4b` 尚待完整业务验证 |
| `model_dir` | 空字符串 | 使用上述默认根目录；显式目录同时用于图文与语音资源 |
| `backup_model_path` / `backup_projector_path` | 空字符串 | 已安装配套备用路径；候选仍须满足目录验证状态，不临时下载 |
| `local_backend` | `auto` | `auto`、`cuda` 或 `cpu` |
| `profile` | 默认 `ModelProfile` | 服务商、地区、端点、具体模型、模式、上下文预算、能力与验证证据、凭据引用 |
| `cloud_memory` | `false` | 独立允许向当前在线提供方发送长期记忆候选进行检索 |
| `cloud_observation` | `false` | 独立允许后台自动观察向在线提供方发送截图 |
| `voice_components` | `["asr", "tts", "realtime"]` | 已选择的识别、朗读、实时识别组件；允许空列表。单识别组件固定对应模式，任一识别组件均可选输入设备；两者齐全才可切换模式 |

`profile` 的服务商／地区默认 `custom`，端点／模型／凭据引用默认空，模式默认 `default`，上下文预算默认 16384 token（范围 1024–2000000），声明能力默认只有 `text`。可声明 `text`、`image`、`tools`、`stream`、`cancel`、`json`；`verified_capabilities`、`verified_at` 与 `verification_fingerprint` 记录显式合成验证结果。声明不等于实测证据，预设本身也不自带成功验证。

验证摘要绑定服务商、地区、端点、模型、模式、上下文预算、能力声明和 `credential_ref`；改变上述任何项都不能沿用旧证据。Key 轮换分配新引用，因此也使旧验证失效。本地优先自动转在线要求完整桌宠能力证据；优先在线可使用未验证配置进行基础文字对话，图片与工具仍受验证门槛约束。HTTPS 为默认要求，仅本机回环开发地址允许 HTTP；端点不能携带用户名、密码、查询串或片段。

默认人设原文：

> 你是一位温柔、机灵的桌面伙伴，陪我工作和学习。自然地说中文，关心但不过度打扰。

默认系统提示词原文：

> 回复简短自然，通常一到两句话。看不清或无法确认的事情要直说，不要编造。

修饰键为 Alt、Ctrl、Shift、Meta/Win；Meta 与 Win 等价，不重复计数。合法写法也可能因系统注册冲突失败，程序保留旧绑定。切换 TTS 表单时音色会重置：Kokoro 为 46，Melo 为 0；这与首次启动默认值不同。

## 保存、草稿与本次运行状态

| 操作 | 实际影响 |
| --- | --- |
| 点击“保存设置” | 按策略校验本地模型文件及形象，预注册热键，后台保存成功后应用；关闭麦克风、取消回复并释放模型，清除临时朗读覆盖 |
| 关闭、Esc 或收起控制中心 | 有配置改动时按上述路径自动保存；失败或保存期间又修改草稿时保留窗口 |
| 保存或清空记忆 | 独立于配置表单；取消当前任务并清空短期会话 |
| 使用这个形象 | 先保存三个形象选择字段，再严格试载并切换角色、更新窗口图标；失败恢复原选择，保留会话、收音和其他配置草稿 |
| 切换对话输入附近“有其他声音时暂停朗读” | 持久保存开关，立即调整检测策略，保留当前会话 |
| 对话朗读按钮/自然语言控制 | 本次运行的临时覆盖；重启或普通配置保存恢复已保存偏好 |
| 托盘退出 | 结束应用；不调用控制中心的关闭自动保存，先保存编辑中的草稿 |

“人设”“语音与行为”“模型设置”共用一份配置草稿；切换标签会保留草稿和各页滚动位置，不会提交配置。“保存设置”不代替“保存记忆”或“使用这个形象”。

Key 只在密码框和本次内存事务中保留，不属于 `Settings` 或普通 JSON。输入 Key 即使未改变其他字段也算未保存；失败不清草稿，保存期间继续编辑也保留新值。只有成功快照与当前密码／模型草稿完全一致才清空密码框；不一致时更新已保存凭据基准，必要时为剩余草稿分配新引用，允许继续保存。清空尚未持久化的新 Key，只恢复匹配当前端点的已保存引用。

凭据事务先将新引用写入 Windows 凭据管理器，再提交配置；配置写入失败会回收本次新引用，旧 Key 保持可用。命名空间为 `desktop-ai-pet/model-api/`，独立于官网 OAuth。引用含端点摘要与随机版本，运行时读取前检查端点匹配；更改端点不自动向新服务商转发旧 Key。验证调用使用合成资料，可能产生服务商费用，验证成功本身不代表配置或凭据已经保存。

配置与记忆写入采用同目录临时文件再替换。持久化操作已开始时会等待完成，取消不回滚已保存结果。错误配置原文件保留；修正前不要用默认值覆盖需要恢复的原始文件。

## 配置接口与生命周期

当前界面的运行方式与高级参数只影响呈现层，原配置字段保持兼容。密钥草稿绑定服务地址后，更换预设端点或手工修改地址会清空旧草稿并要求重新填写；同端点的其他参数编辑不会清空密钥。首次尚未填写地址的草稿可继续完成首个地址，在选择完整预设、开始测试或取得保存快照后绑定。

配置的唯一入口是 [config.py](../../pet/config.py) 的 `Settings/load_settings/save_settings`；推理子对象由 [ai/settings.py](../../pet/ai/settings.py) 解析和校验。UI 通过 `PanelSettings` 汇集人设、偏好和 `ModelPage/AIPage` 快照，交给 Runtime 的后台存储事务；布局模块不自行落盘。普通设置 JSON 与无秘密的安装计划分别校验，不能把计划文件当作用户配置或凭据备份。

[安装计划](../../pet/ai/install_plan.py) 的 `prepare_plan` 只消费传入设备事实和可选已验证档案，核算应用/模型同卷空间及下载解压暂存，不探测设备或读取 Key；`save_plan/load_plan` 只接受已知字段。设备检测与合成 API 验证由 [ai_tasks.py](../../pet/ai_tasks.py) 运行，界面使用请求 ID、配置摘要和探测代次屏蔽迟到结果；隐藏模型页会取消验证，保留未保存草稿。使用说明见 [模型与在线 API](使用指南.md#模型与在线-api070)。

语音会话在后台按 `ai.model_dir` 重配根目录，目录变化释放旧 ASR/TTS 会话，不移动文件。`voice_components` 是组件选择契约，不是磁盘存在性的证明；运行时仍校验实际资源，缺失时给出原因。保存配置、取消对话、关闭收音和切换目录分别沿用各自锁与代次，不允许旧任务恢复新会话的麦克风。

## 形象选择与失败恢复

“更换形象”的导入、下载、预览不写当前选择。点击“使用这个形象”只修改 `avatar_image`、`platform_model_version`、`platform_expression_version`：默认清空三项，图片使用规范化副本标识，模型使用已安装版本标识，更换时清空旧表情选择。其他业务配置不随形象提交；保存成功后才在真实 Avatar 严格试载，成功才标为当前使用。

保存失败不改桌宠；试载失败保留原桌宠并异步恢复原三项字段，不以旧快照覆盖其他设置。恢复记录也失败时明确提示重启前重新选择原形象。默认/模型候选必须经过真实动态加载，不能把静态回退视为成功；启动恢复已保存形象的容错回退仍保留。用户操作说明见 [形象与预览](使用指南.md#形象与预览)。

下表路径以当前项目/安装目录为根。源码版和安装版分别保存，程序不自动迁移；默认模型目录则共用。

日常应用在内存处理截图、录音和短期会话，不自动将其正文存盘；日志记录运行状态，不作为聊天历史。**验收脚本会保存合成文字、音频和虚拟窗口截图**，应按脚本说明理解其数据范围。源码仓库通过 [.gitignore](../../.gitignore) 排除本机数据、运行库、模型和环境。

控制中心“运行日志”标签读取当前日志尾部最多 256KiB、1000 行，当前标签选中且控制中心显示期间每秒异步刷新，切换到其他标签或收起控制中心后停止；它不是完整历史日志检索器。需要轮转前记录时查看 `pet.log.1`、`pet.log.2`。

## 记忆限制

总量最多 6000 字；对话追加单条 1–500 字，手动编辑不受单段 500 字限制。重复整行不追加；保存时检查敏感内容，对话保存还检查来源文本。过滤不等于完备的秘密识别或加密。

0.6.0 只在模型按需调用查询工具后读取候选，再按 token 容量选择最多 700 字相关原文，无关时返回空结果；不再每轮强制查询。存储格式未迁移，不存在向量索引或自动总结数据库。公开 0.5.6 的每轮检索是历史行为，0.6.0 的分组复验与已知差异见模型自主工具对话说明。损坏 JSON 会保留文件并读作空记忆，需修正后再保存。

## 模型、网络与备份

已发布 0.6.0 可更换图文 GGUF 和匹配 mmproj，语音模型根目录固定。本地新源码增加 `ai.model_dir`，图文与语音统一采用所选根目录；已有显式 GGUF 路径不会在读取配置时自动覆盖。修改位置与安装前提见 [安装与发布](../发布与安装/安装与发布.md)。

0.6.0 的本地推理访问回环服务，使用临时凭据并禁用环境代理。本地新源码也可连接用户配置的在线 API，Key 自备、服务商直接计费；API-only 不要求本地权重或语音组件。安装下载器使用外网，不能将推理客户端设置推广为“安装时也禁用代理”。

在线普通请求可能发送对话文字、必要历史、工具结果及明确附图。`cloud_memory` 与 `cloud_observation` 各自默认关闭，不随策略改变而自动开启。未允许云端记忆检索时不提供相应工具、不发送候选；允许后可能按容量分批发送整个本地记忆库的候选内容，不能描述为仅上传最终摘录。记忆持久文件和新记忆写入仍在本机，录音仍本地识别。后台截图开关不等于禁用用户明确附图或模型按需截图能力；当前可用能力还受验证证据约束。

在退出桌宠后备份 `data/settings.json`、`data/memory.json`、`data/appearances/` 和 `data/platform-resources/` 可保留配置、记忆及导入形象，不能据此备份 Windows 凭据管理器中的 Key。换机器时需重新提供 Key；换目录时需要自行复制数据，模型路径及输入设备编号仍需核对。程序没有自动跨目录迁移或云同步。卸载保留边界见 [安装与发布](../发布与安装/安装与发布.md#升级与卸载)。
