玄司 Xuansi 在线安装版

文档同步日期：2026-10-17。本版 0.6.0 默认采用 Qwen3.5-9B Q4_K_M 和匹配投影，用户已接受已知差异并授权更新本机和 Release。实际版本和源码来源以 release.json 与 GitHub v0.6.0 为准；构建、安装及公开验证状态见 omx_wiki/发布与安装/验收/安装包0.6.0发布验收.md。
发布入口：https://github.com/DesktopPetXuansi/Xuansi/releases/tag/v0.6.0
纯英文偶尔未选择 natural 而沿用 fast；真实模型并非全部语义全绿。RTX 4070 Laptop 8 GiB 仅测试 4096 上下文，占约 7.5 GiB、余约 650 MiB，不保证其他设备、更大上下文或延迟无退化。历史失败和分组复验见 omx_wiki/对话与记忆/验收/模型自主工具对话候选验收-2026-10-16.md。
已有 data/settings.json 不自动覆盖模型路径，新装默认 9B；老用户需在模型设置选 9B 主模型及匹配投影后保存。原 4B 文件保留。安装器会清理三个退役控制模块及其字节码，不触碰 data。

需要 Windows 11 x64、兼容 CUDA 12.4 的 NVIDIA GPU 与驱动，以及可访问 PyPI、GitHub 和 Hugging Face 的网络。
安装包自带 Python 3.13，无需另装 Python 或 Git，不设置开机启动。

图文模型及匹配投影保存在 D:\AI\Models\desktop-pet\qwen3.5-9b，其余模型沿用父目录，需要 D 盘。主模型文件为 Qwen3.5-9B-Q4_K_M.gguf，投影文件为 mmproj-F16.gguf，两者首次下载约 6.60 GB；建议至少预留 20GB 磁盘空间（非已测最低要求），应用安装盘也需容纳 Python 依赖和推理引擎。
首次安装会下载较大的模型；请保持联网，普通网络中断通常可重新运行安装包续传。摘要或续传校验反复失败时，按 omx_wiki/客户端/故障排查.md 核对并处理对应损坏的 .part；脚本不会自动清除所有坏缓存。
安装日志保存在安装目录 data\setup.log。日志含本机路径，分享前请脱敏。

源代码采用 Apache-2.0；内置玄司图片保留版权。Python 和其他第三方组件分别适用各自许可证，详见 omx_wiki/项目/THIRD_PARTY.md 和各组件许可文件。

源码版与安装版分别使用各自目录的 data，不自动迁移；安装到原目录会保留已有设置、记忆和导入形象。
卸载删除安装包部署的文件、入口及 runtime/python 基础 Python；保留安装后生成的 .venv、data、runtime/llama、下载压缩包和 D 盘模型。保留 .venv 不代表卸载后仍能启动。模型可能由其他目录共用，需要时按实际情况手动清理。
本版本未使用付费代码签名证书。请核对同目录或对应 GitHub v0.6.0 的 SHA256SUMS.txt，实际公开状态见发布验收。
