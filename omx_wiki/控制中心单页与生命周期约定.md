# 控制中心单页与生命周期约定

2026-10-15 源码客户端已把对话、人设、记忆、语音与行为、模型、形象、官网资源、上传、日志整合到一个 Panel。顶部定位仅滚动，分区可同时展开，不重建草稿。托盘三入口和 Ctrl+Alt+Space 统一唤起控制中心，QuickChat 已删除。

嵌入旧 QDialog 必须显式设置 Qt.Widget 标志并处理 Enter/Esc、accept/reject，不能仅设置父对象。形象隐藏停止 GL 预览并拒收迟到导入结果，日志隐藏停止轮询；上传隐藏继续运行，只有显式取消或完整退出才取消并等待线程。

配置统一走既有保存事务，失败保留草稿；记忆单独保存。同站点上传表单和入库回执复用；实际提交前再次校验当前官网地址，防止同页导航绕过换站检查。

完整 Python 回归 441 passed、2 skipped，Ruff 和编译检查通过。真实 Windows 菜单/热键 20 项、原生单页窗口和 Live2D 预览 12 项全部通过；后者网络使用替身，不能当作新一轮服务器上传闭环。
