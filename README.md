# 玄司 Xuansi · 本地 AI 桌宠

一个运行在 Windows 上的桌面 AI 伙伴。玄司能结合鼠标行为理解屏幕、文字聊天、进行语音对话，并记住你明确指定的事情。名字、人设、系统提示词、模型参数和桌宠形象都可以在软件中调整。

首次安装需要下载依赖和模型；日常推理在本机完成，无需云端账号或 API 密钥。项目源代码采用 [Apache-2.0](LICENSE)，内置玄司图片[保留版权](assets/xuansi/LICENSE)，模型及第三方组件分别遵循各自许可。

## 功能

| 能力 | 当前实现 |
| --- | --- |
| 屏幕理解 | 根据点击、拖拽结束、滚动和停留触发观察；默认读取鼠标所在显示器的完整画面，可切换为鼠标附近 |
| 自定义角色 | 修改名字、人设和系统提示词；支持聊天与附图对话 |
| 连续语音 | 手动启麦，自动判断一句话结束，本机识别和朗读，可随时关闭 |
| 长期记忆 | 明确说出“记住……”或手动编辑，支持查看、修改、清空和重启恢复 |
| 形象替换 | 软件内导入 PNG、JPG、BMP、透明 GIF、动态 WebP、APNG，预览后应用，可恢复默认玄司 |
| 动画 | 静态图附带轻微身体动作；导入动图按原有帧序循环播放并保留透明度 |
| 减少打扰 | 气泡不自动抢焦点，透明区域穿透点击；其他软件发声时停止朗读，用文字回应 |
| 快捷对话 | 默认 `Ctrl+Alt+Space` 在鼠标所在显示器右下角打开对话框 |
| 配置与日志 | 软件内调整模型、采样参数、设备、观察频率和快捷键，查看运行日志 |

**当前语音不是流式或全双工。** 一轮流程是“录完一句 → 识别 → 获取完整模型回复 → 合成语音 → 播放”，朗读时暂停收音。图文模型目前使用 Qwen3.5，未集成 MiniCPM-o 的原生全双工链路；不同模型的实际能力不能保证完全一致。

## 安装与启动

### 环境

- Windows 11 x64、Git、Python 3.13（安装后可运行 `py -3.13`）。
- 当前安装脚本使用 llama.cpp 的 Windows CUDA 12.4 构建，需要兼容的 NVIDIA GPU 和驱动。
- 已验证开发设备为 RTX 4070 Laptop 8GB、32GB 内存；这是一组实测配置，不是经过全面验证的最低配置。CPU、AMD GPU、macOS 和 Linux 尚未适配验收。
- 建议预留至少 15GB 可用磁盘用于虚拟环境、模型、压缩包和解压文件；首次下载可能较久。

**模型目录目前固定为 `D:\AI\Models\desktop-pet`。** 如果没有 D 盘，安装前请把 [pet/config.py](pet/config.py) 和 [scripts/download_assets.py](scripts/download_assets.py) 中的 `MODELS` 改成同一个可写目录。软件菜单能更换图文模型路径，语音模型目录仍依赖这个常量。

```powershell
git clone https://github.com/DesktopPetXuansi/Xuansi.git
cd Xuansi
py -3.13 --version
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
```

安装脚本创建项目内的 `.venv`，按 [requirements.lock.txt](requirements.lock.txt) 安装依赖，下载并校验图文模型、语音模型和推理引擎，然后创建快捷方式。它目前会下载全部预设模型，包括可选的 Kokoro，不设置开机启动。上述执行策略参数仅作用于这次 PowerShell 进程。

下载来源、固定版本和 SHA256 见 [assets-manifest.json](assets-manifest.json)。下载支持断点续传；网络中断后可以重新运行安装脚本。仓库不包含模型权重、虚拟环境、推理运行库或打包好的安装程序。

安装完成后，双击桌面的 **“玄司 AI 桌宠”**、项目内的 **“启动桌宠.lnk”**，或 `启动桌宠.vbs`。也可以在项目目录执行：

```powershell
.\.venv\Scripts\pythonw.exe -m pet
```

重复启动会打开已有面板。关闭面板只是收起窗口，完全退出请使用托盘菜单中的 **退出**。

## 使用方式

点击角色打开面板，拖动角色调整位置。顶部菜单和托盘菜单提供配置、日志与形象入口。

1. **聊天**：直接输入文字；“看一眼”让它观察当前屏幕，勾选“这次对话附上屏幕画面”可为文字提问附图。
2. **语音**：点击“开启连续对话”，等待“正在聆听”后说话，停顿约 0.8 秒结束一句，单句最长约 12 秒。再次点击关闭收音和播放；启动和重启都不会自动启麦。
3. **人设**：修改名字、性格及系统提示词，点击保存。
4. **记忆**：输入或说出“记住，我喜欢简短的回答”，也可在记忆页编辑。仅明确要求保存的事项进入长期记忆，不自动归档所有聊天。
5. **偏好**：调整观察范围、频率、角色大小、麦克风、音色和语速。默认 Melo 中英单音色，Kokoro 中英多音色可选但速度较慢。
6. **配置 → 模型参数与快捷键**：调整 temperature、top_p、回复 token 上限、上下文、CPU 线程、GPU 层数，以及 GGUF 和配套视觉组件。保存模型配置会结束当前回复并关闭麦克风，下一次请求加载新设置。
7. **日志 → 运行日志**：查看最近 1000 行，支持级别筛选、刷新和自动跟随。隐藏窗口后停止刷新。

`Ctrl+Alt+Space` 打开右下角快捷对话框，回车发送、Esc 收起，也支持连续语音。它与主面板共用当前会话、人设和记忆。快捷键可更换；冲突或保存失败会保留原设置。

### 替换形象与透明动图

选择 **形象 → 更换桌宠形象**，导入本机图片，确认预览后点击“应用形象”。更换立即生效并在重启后保留，不更改名字、人设和记忆。托盘有相同入口，也可恢复默认玄司。

- 静态图支持 PNG、JPG、BMP；动图支持 GIF、WebP、APNG。透明区域穿透点击，普通白底或画出的棋盘格不会自动变透明。
- 输入最多 20MB、单帧 1600 万像素、动图最多 120 帧，累计原始解码最多 1.6 亿像素。超限会提示降低分辨率或帧数。
- 静态副本最长边最多 1536；动图最长边最多 512，累计副本像素最多 1200 万，以 APNG 保存透明度和帧时长。帧时长限制为 20–10000ms，播放时循环。
- 静态图片使用呼吸、思考、回应、休眠和移动等轻微身体动作；没有眨眼、口型、骨骼或 Live2D 动画。导入动图使用自身画面，不会自动生成新动作。
- 导入和预览会生成本机副本，原文件移动后仍可使用；恢复默认不会删除已导入的副本。相同像素内容会去重，缺失或损坏时暂时回退默认形象。

## 屏幕理解与工作时的行为

自动观察默认至少间隔 20 秒，捕获鼠标所在显示器的完整画面，缩小到长边最多 1600 像素，并以红圈标记鼠标。可在“配置 → 语音与行为 → 观察范围”切换到鼠标附近的 640 × 448 区域。范围设置同时用于自动观察、“看一眼”和附图对话。多显示器时只读取鼠标所在的一块，不是连续视频录制。

整屏缩小会影响小字识别，截图无法看到遮挡、最小化的窗口或屏幕之外的内容。模型只提供文字、语音和预设动作，不接管键盘鼠标，也不执行模型生成的命令。

- 默认角色停在原地，自动观察不朗读，无须回应时保持安静。角色实体区域用于交互，透明部分穿透点击，气泡不自动抢输入焦点。
- 检测到全屏、锁屏或前景桌面暂不可用时，暂停观察及语音，隐藏角色并释放模型；恢复桌面后显示角色，语音需要手动重新开启。
- “休眠”取消推理、停止收音和播放、卸载模型；可用内存低于 2GB 也会休眠。没有对话且麦克风关闭时，闲置约 120 秒卸载模型。
- 推理进程使用较低优先级，默认 4 个计算线程、单请求并发。推理仍会占用显存和计算资源，重任务或游戏期间可手动休眠。
- 其他软件发声时停止朗读，仅显示文字和气泡，被打断的回复不会稍后补播。安静 1.5 秒后，后续回复恢复朗读；检测失败时保持文字模式。

声音回避只查询 Windows 输出设备及应用会话的电平和静音状态，不录制其他软件音频。电平约每 100ms 采样，突然出现的声音可能短暂重叠；极短提示音、特殊独占设备和设备切换不能保证零延迟识别。语音结束判断采用能量断句，持续噪声或声音过轻可能导致误触发或漏触发。

## 模型和本机数据

| 用途 | 默认组件 |
| --- | --- |
| 图文理解与聊天 | Qwen3.5-4B Q4_K_M + 匹配 mmproj，llama.cpp CUDA |
| 语音识别 | SenseVoice int8，sherpa-onnx CPU |
| 默认朗读 | MeloTTS 中英 ONNX，单音色 |
| 可选朗读 | Kokoro int8 中英，多音色 |
| 桌面界面 | Python 3.13 + PySide6 Essentials |

更换图文模型时，需要选择当前 llama.cpp 构建支持的 GGUF 和匹配视觉组件。过大模型可能显存不足，不是任意 Hugging Face 模型都能直接加载。超长人设或输入会提示缩短，普通长对话会移除最早的上下文。

| 位置 | 内容 |
| --- | --- |
| `data/settings.json` | 用户设置 |
| `data/memory.json` | 明确保存的长期记忆，普通文本 JSON |
| `data/appearances/` | 导入形象的本机副本，去除原图元数据 |
| `data/pet.log` | 运行日志，按 512KiB 轮转并保留两份备份 |
| `runtime/` | 下载的 llama.cpp 和运行库 |
| `D:\AI\Models\desktop-pet` | 默认模型目录 |

截图、麦克风音频和短期会话只在内存中处理；日常应用不保存其正文，日志不记录聊天、截图和录音内容。长期记忆最多 6000 字，每轮按关键词和最近记录选取最多约 700 字，适合称呼、偏好和简短事项。清空记忆会取消当前回复并清掉短期上下文。记忆不加密，不应存入密码、密钥或证件等秘密。

推理服务仅监听 `127.0.0.1`，使用每次启动随机生成的会话凭据，客户端禁用环境代理。安装脚本联网下载公开文件，日常推理不调用云端接口。上述数据、权重和运行环境均不进入本仓库；不要将自己的 `data/` 上传到 Issue 或公开仓库。

## 开发与验证

`pet/` 是应用模块，`tests/` 是逻辑与生命周期测试，`scripts/` 包含下载、素材处理和验收工具，`assets/` 是内置角色素材。

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check pet tests scripts
.\.venv\Scripts\python.exe -m pet --smoke
```

执行 `--smoke` 前请先退出正在运行的桌宠，否则单实例机制只会打开已有面板。真实模型和原生窗口检查在 `scripts/verify_*.py`，需要已下载的权重及可用桌面。部分脚本会显示虚拟测试窗口，运行前请退出桌宠，并先阅读对应脚本的用途。验证产物保存在忽略的本机目录中。自动测试不等于真实麦克风、听感和日常工作流畅度的主观验收。

当前实现及历史验收记录：[实施规格](实施规格.md)、[初版验收](验收记录.md)、[菜单与免打扰](菜单与免打扰验收.md)、[整屏观察](整屏观察验收.md)、[玄司形象](玄司形象验收.md)、[透明动图与形象菜单](形象菜单与透明动图验收.md)、[开源发布](开源发布验收.md)。记录中的“本机已安装”等状态仅描述开发设备，不代表新克隆已经具备环境。

常见问题：

- **模型不存在或安装失败**：先检查 D 盘路径、可用空间和下载网络；读取安装输出。校验失败的文件不会启用。
- **无法收音**：检查 Windows 麦克风权限，在偏好中选择设备，保存后重新开启连续对话。
- **没有朗读**：先看是否显示“其他软件有声音”或“声音检测暂不可用”；安静后用“试听当前音色”检查输出设备和音量。
- **卡顿或显存不足**：先休眠释放资源，缩短上下文或调整 GPU 层数；CPU 卸载会影响速度，效果依设备而异。
- **形象仍有白底或棋盘格**：源文件必须有真正的透明通道，软件不自动抠图。
