# 首期开发任务

- [ ] T01：接口、设计规范和本地运行配置。验收：前后端使用同一字段和路径；验证：契约与配置检查。
- [ ] T02：PostgreSQL 迁移、健康检查及版本下载。验收：数据库实际启动、迁移可重复运行、公开下载元数据真实；验证：Go 集成测试。
- [ ] T03：邮箱注册/验证、登录和密码恢复。验收：真实邮件通道、会话与 CSRF、密码摘要；验证：账号成功与失败路径。
- [ ] T04：个人资源及版本管理。验收：所有者隔离、模型与动作/表情精确依赖；验证：跨用户权限与依赖测试。
- [ ] T05：上传、异步校验与不可变发布包。验收：安全解包、SHA256、配额原子处理、幂等重试；验证：正常包和恶意 ZIP。
- [ ] T06：资源库、manifest 和下载授权。验收：私有文件鉴权及稳定版本清单；验证：下载字节与摘要、撤销后拒绝。
- [ ] T07：官网、下载、文档和资源浏览页面。验收：真实品牌素材、响应式布局、无虚构内容；验证：构建、浏览器截图及可访问性。
- [ ] T08：账号、上传、资源编辑及管理员页面。验收：操作对接真实 API，完整空/错/忙状态；验证：浏览器注册登录和上传闭环。
- [ ] T09：客户端 OAuth/资源安装服务。验收：PKCE、后台下载、摘要校验、安全原子安装与离线持久化；验证：Python 逻辑及契约测试。
- [ ] T10：客户端模型/动作/表情选择与应用。验收：参数降级、试载失败回退、默认形象回归；验证：原生客户端测试与实际渲染。
- [ ] T11：存储、邮件、worker、Docker/Caddy 与运行说明。验收：本地可复现运行、生产参数完整；验证：启动及健康检查。
- [ ] T12：桌面安装载荷排除网站。验收：web 不进入桌面安装器，旧安装流程保持；验证：构建脚本相关测试。
- [ ] T13：综合验收与独立审查。验收：前端检查、Go 测试/静态检查、客户端回归、资源完整闭环；验证：docs/开发验收.md 中的新鲜证据。
