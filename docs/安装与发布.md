# 安装与发布

核对日期：2026-10-11。安装、下载和构建规则以 [setup.ps1](../setup.ps1)、[基础下载器](../scripts/download_assets.py)、[实时下载器](../scripts/download_realtime.py)、[构建脚本](../scripts/build_installer.ps1) 和 [安装器定义](../installer/online.iss) 为准。这些脚本在 0.5.5 与 0.5.6 之间未改变；功能差异见 [核对记录](文档核对记录-2026-10-11.md)，本次正式包见 [发布验收](../安装包0.5.6发布验收.md)。

## 环境与公开下载

- Windows 11 x64（安装器最低系统版本 10.0.22000）。
- 当前下载的是 llama.cpp Windows CUDA 12.4 构建，需要兼容的 NVIDIA GPU 与驱动。
- 默认模型盘为 `D:\AI\Models\desktop-pet`；在线安装器要求有 D 盘，没有更换全套目录的选项。
- 建议至少预留 15GB 空间，应用盘与模型盘分别留余量；这不是安装脚本的容量检查或经硬件矩阵验证的最低值。
- 首次安装需要访问 PyPI、GitHub、Hugging Face；构建另外需要 NuGet。日常推理在本机完成。

历史开发设备为 RTX 4070 Laptop 8GB、32GB 内存，不能用这组实测设备推定所有最低配置。CPU 路线、AMD GPU、macOS 和 Linux 尚未适配验收。

从 [GitHub Latest](https://github.com/DesktopPetXuansi/Xuansi/releases/latest) 取得公开安装器及 `SHA256SUMS.txt`；0.5.6 的来源、发布时间、大小与摘要见 [发布验收](../安装包0.5.6发布验收.md)。安装器未做代码签名，可将本机摘要与发布校验文件比对：

```powershell
Get-FileHash .\Xuansi-0.5.6-windows-x64-setup.exe -Algorithm SHA256
```

2026-10-10 的 [本地构建和安装记录](../安装包0.5.6验收.md) 是旧候选快照，其提交及摘要不能代替本次正式构建。

## 在线安装

安装包包含 Python 3.13.15，无需预装 Python 或 Git。按当前用户安装，默认目录为 `%LOCALAPPDATA%\Programs\Xuansi`，不要求管理员，不添加开机启动。

安装后从开始菜单“玄司 AI 桌宠”启动；“玄司 AI 桌宠（安装版）”桌面入口需安装时勾选，默认不选。源码版入口不会自动替换为安装版。

安装器部署文件后运行 `setup.ps1 -SkipShortcuts`，安装锁定版本的 Python 依赖，并下载、校验模型和推理运行库；pip 不做项目固定的逐包 hash 校验。失败时明确显示环境未完成并返回失败状态；程序文件已部署不代表可以运行。检查 `data/setup.log`，联网后重新运行安装器，或使用开始菜单“重新下载依赖与模型”。

## 源码安装

准备 Git 与 64 位 Python 3.13：

```powershell
git clone https://github.com/DesktopPetXuansi/Xuansi.git
cd Xuansi
py -3.13 --version
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
.\.venv\Scripts\pythonw.exe -m pet
```

已有工作树无需重新克隆，但应确认正在运行的入口与所读源码是同一目录。正式安装版按 `release.json` 的提交核对；仓库后续补录文档不会自动替换已发布安装包。

没有 D 盘时，安装前将 [pet/config.py](../pet/config.py) 和 [scripts/download_assets.py](../scripts/download_assets.py) 中的 `MODELS` 改为同一个可写目录；实时下载器导入后者常量。软件仅能修改图文模型路径，不能搬迁所有语音模型。这里说明源码适配方法，本轮没有修改这些业务或下载脚本。

首次创建环境时，可以给 `setup.ps1` 传 `-PythonPath` 指定 64 位 3.13 解释器；否则优先使用包内 Python，再使用 `py -3.13`。已有 `.venv` 会直接复用；版本或位数错误会失败，不自动重建。依赖安装按运行锁文件执行，制作 PSD 的 [可选锁文件](../requirements-rigging.lock.txt) 不会自动安装。

源码脚本创建项目“启动桌宠.lnk”和桌面“玄司 AI 桌宠”入口；若同名入口指向其他目录，会报错而不覆盖。也可直接使用项目的 [启动桌宠.vbs](../启动桌宠.vbs) 或上述模块命令。

## 下载版本与校验覆盖

| 范围 | 事实来源与校验 |
| --- | --- |
| 基础七项资源 | Qwen 权重/投影、llama.cpp/CUDA 包、SenseVoice、Melo、Kokoro；[下载器](../scripts/download_assets.py) 固定版本与 SHA256 |
| 实时识别三项 | encoder、decoder、tokens；[独立脚本](../scripts/download_realtime.py) 固定 Paraformer 提交 `8e40c43232a1c5c66c82111efc5820d3accca11b` 及各项 SHA256 |
| 基础资源清单 | [assets-manifest.json](../assets-manifest.json) 仅记录基础七项，是下载器生成结果，不是全部依赖清单或可编辑的下载输入 |
| Python 包 | [requirements.lock.txt](../requirements.lock.txt) 固定版本，但没有逐包 hash，也未启用 `--require-hashes` |
| 构建工具 | 构建脚本固定 Python 3.13.15、Tools.InnoSetup 7.1.0 NuGet 包及 SHA256 |

安装会下载全部预设模型，包括可选 Kokoro，不能按当前偏好跳过。已下载正式文件摘要匹配才复用；`.part` 支持 Range 续传，服务器忽略 Range 并成功返回完整文件时从头下载；HTTP 416 等错误不会自动清除旧 `.part`。基础资源最多三个并发，实时资源两个并发，每项约限 2MiB/s。

普通网络异常有重试，摘要或续传起点不匹配则失败；损坏的 `.part` 不会自动清除，反复校验失败时需根据日志处理对应文件，见 [故障排查](故障排查.md)。下载压缩包通过摘要校验不等于应用每次启动都重校验全部解压文件。部分摘要为首次 HTTPS 下载后计算并固定，不是作者签名；许可与来源见 [第三方记录](../THIRD_PARTY.md)。

## 升级与卸载

1. 保存草稿，从托盘“退出”结束旧实例。安装器不自动关闭或重启运行中的桌宠。
2. 运行新版安装器并选择原目录；原目录下的设置、记忆与导入副本不属于包内文件，升级会保留。
3. 从该安装版入口重新启动；核对安装目录 `release.json` 的 `version` 和 `commit`。
4. 源码版和安装版的数据各在自己的 `data/`，不自动迁移；需要时退出应用后按 [备份说明](配置与数据.md#模型网络与备份) 复制。

正常卸载删除安装包部署的源码、素材、入口及 **`runtime/python/` 基础 Python**；安装后生成的 `.venv/`、`data/`、`runtime/llama/`、下载压缩包和 D 盘模型保留。保留虚拟环境不代表卸载后还能启动，它依赖的包内基础 Python 已被删除。模型可能被其他目录实例共用，清理前按实际使用情况确认。

没有自动更新、自动跨目录迁移或自动删除共享模型的功能。0.5.1 候选安装包未公开，其修复随后纳入 0.5.2；其他发布历史见 [验收索引](../文档索引.md#历史验收与发布证据)。

## 构建与发布

在 Windows、Git 和可访问 NuGet 的环境中，先完成检查并提交要打包的文件，再执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build_installer.ps1
```

脚本要求 `git status --porcelain` 为空，包括 Git 可见的未跟踪文件；忽略目录不计入该检查。需要保留本机未跟踪工程时，另建干净 worktree 构建已提交版本，不能把主工作区内容视为已打包。

脚本从 `git archive HEAD` 导出源文件，下载、校验并解压构建工具，不安装全局工具；ISCC 使用当前工作树的 `online.iss` 和安装须知，干净前提保证它们与提交一致。它**不运行测试，也不自动上传 GitHub**。

| 产物 | 内容 |
| --- | --- |
| `dist/Xuansi-<VERSION>-windows-x64-setup.exe` | 在线安装器 |
| `dist/SHA256SUMS.txt` | 本次安装器摘要 |
| 包内 `release.json` | 版本、Git 提交、Python 与 Inno 版本 |
| `build/installer/`、`build/tools/` | 导出暂存树、工具缓存 |

[VERSION](../VERSION) 必须是三段数字；发布标签应与版本一致。安装器包含 Git 导出的文件及 Python，但通过 `online.iss` 的明确排除表去掉既有 PSD、拆层图片和指定 Cubism 工程；不是自动排除任意新增制作文件。未跟踪工程、用户数据、本机环境与模型不会由 Git 导出。

构建完成、隔离安装/升级、真实模型和原生窗口检查、来源与摘要核对、GitHub 上传及公开下载复验是不同步骤。本次状态见 [0.5.6 发布验收](../安装包0.5.6发布验收.md)，历次证据见 [文档索引](../文档索引.md)，许可见 [THIRD_PARTY.md](../THIRD_PARTY.md)。
