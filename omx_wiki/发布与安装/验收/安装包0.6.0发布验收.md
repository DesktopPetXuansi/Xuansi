## 交付内容

用户原话、上下文、提示和原生 tools 直接交给模型；模型可以直接回答或调用工具，执行结果如实返回后继续对话。不通过“无需回应”等词句控制正文显示。观察结束工具可以与本轮提醒正文并存，避免强制重试导致重复提醒；动作回执等待末帧实际绘制完成。

0.6.0 新安装默认使用 `D:/AI/Models/desktop-pet/qwen3.5-9b` 下的 9B Q4_K_M 和匹配 F16 投影。原有 4B 文件保留。已有配置不会由安装器自动覆盖；本机按用户此次选择只更新模型和投影两个路径，其他配置与记忆保留。

## 来源与升级核对

正式安装器由干净提交经 `scripts/build_installer.ps1` 的 Git archive 构建。安装包内 `release.json` 提供版本和完整来源提交；安装器摘要通过随附 `SHA256SUMS.txt` 交付。实验构建 `d528c23` 的历史记录不替代正式构建来源。

本机升级检查版本、来源提交、Inno 注册目录、三个退役控制模块清理及个人文件；模型路径变更单独记录并核对其他键值保持一致。

公开交付入口为 [v0.6.0 Release](https://github.com/DesktopPetXuansi/Xuansi/releases/tag/v0.6.0)。发布后通过重新下载安装器核对摘要；完整发行结果由仓库本页补录，安装器内的来源信息仍以其 `release.json` 为准。
