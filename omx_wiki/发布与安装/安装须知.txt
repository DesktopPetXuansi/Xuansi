玄司 Xuansi 在线安装版

文档同步日期：2026-10-18。本版 0.7.0 提供安装前设备检测、本机/在线选择、模型目录和独立语音组件。常用设置使用简明步骤，专业参数默认折叠。版本和源码来源以 release.json 为准，安装及公开验证状态见 omx_wiki/发布与安装/验收/安装包0.7.0发布验收.md。
发布入口：https://github.com/DesktopPetXuansi/Xuansi/releases/tag/v0.7.0
模型对指令和工具的理解仍可能出现误判，部分纯英文回复会沿用 fast 语音引擎。资源占用和延迟受模型、上下文与运行环境影响，尚未验证统一的最低内存和显存要求。已知问题及具体条件见 omx_wiki/归档/对话与记忆/验收/模型自主工具对话候选验收-2026-10-16.md。
标准本机模型为 9B；4B 为实验选项，已有语义验收失败，不作为完整自动备用。安装前检测只估算资源，实际速度需运行确认；CPU、其他服务商与跨设备仍有实测缺口。

需要 Windows 10 1809 或更新系统、x64，以及安装时可用的网络。在线模式不要求 NVIDIA 显卡或本机大模型；本机加速方式由检测结果和用户选择决定。
安装包自带 Python 3.13，无需另装 Python 或 Git，不设置开机启动。

模型和语音目录可在向导中选择，无需 D 盘。已有 D:\AI\Models\desktop-pet 时继续识别，否则默认位于当前用户的 LocalAppData\Xuansi\models。标准 9B 权重和看图组件约 6.60 GB；语音、依赖、引擎及临时空间另计，向导会按所选组件预检。
首次安装只下载所选资源；未选的语音组件不下载，纯在线且不选语音时不下载本机模型。普通网络中断可重试续传；摘要或续传反复失败时按 omx_wiki/客户端/使用指南.md 的故障排查处理损坏的 .part，脚本不会自动删除所有坏缓存。
安装日志保存在安装目录 data\setup.log。日志含本机路径，分享前请脱敏。

源代码采用 Apache-2.0；内置玄司图片保留版权。Python 和其他第三方组件分别适用各自许可证，详见 omx_wiki/项目/THIRD_PARTY.md 和各组件许可文件。

在线服务使用你自己的 API 密钥，由服务商直接计费；点击能力测试可能产生少量调用费用。密钥保存在系统凭据管理器，不放入普通配置或日志。在线对话会发送必要文字、对话记录和工具结果；长期记忆读取与自动截图分别授权、默认关闭。关闭自动截图不禁止单次附图或对话按需截图，录音仍在本机识别。
源码版与安装版各自使用本目录的 data，不自动迁移。升级前退出桌宠；同目录安装保留人设、记忆和导入形象，模型/策略/语音字段按本次选择更新，旧设置备份为 data/settings.before-install-*.json。未选择朗读或实时识别会关闭对应偏好。麦克风不会自动开启。
卸载删除安装包部署的文件、入口及 runtime/python 基础 Python；保留安装后生成的 .venv、data、runtime/llama、下载压缩包和 D 盘模型。保留 .venv 不代表卸载后仍能启动。模型可能由其他目录共用，需要时按实际情况手动清理。
本版本未使用付费代码签名证书。请核对同目录或 GitHub v0.7.0 的 SHA256SUMS.txt，实际公开状态见发布验收。
