# 玄司 · 本地 AI 桌宠

为这台 Windows 电脑制作的桌面伙伴：能聊天、看鼠标所在显示器的完整画面、连续语音对话，并记住你明确指定的事情。模型已下载到 `D:\AI\Models\desktop-pet`，日常运行无需云端账号或 API 密钥。

## 开始使用

双击桌面的 **“玄司 AI 桌宠”**，或本目录的 **“启动桌宠.lnk”**。没有控制台窗口，重复启动会打开已有面板。备用入口是 `启动桌宠.vbs`。

1. 点击右下角的玄司打开面板；拖动角色可以调整位置。默认窗口高度 160，在“偏好”可调为 64–288。
2. **聊天**：输入文字，或点击“看一眼”。要给这次对话附图，勾选“这次对话附上屏幕画面”。
3. **语音**：点击“开启连续对话”，等状态变为“正在聆听”再说话，停顿约 0.8 秒结束一句。再次点击即可关闭收音和播放。它说话时暂停收音，播放完成后继续听，最长一句约 12 秒。
4. **人设**：修改名字、性格、系统提示词，再点保存。
5. **记忆**：说或输入“记住，我喜欢简短的回答”，或者在记忆页编辑。重启后仍在；可随时清空。它只长期保存明确要求记住的文字，不自动归档所有聊天。
6. **偏好**：可关闭自动观察、调长观察间隔、选择麦克风、试听音色。默认 Melo 中英单音色；可选 Kokoro 中英多音色，速度较慢。
7. **形象 → 更换桌宠形象**：选择本地图片，查看静态/播放预览，再点“应用形象”。支持透明 PNG、GIF、动态 WebP、APNG，以及 JPG、BMP；也可以“恢复默认玄司”。托盘菜单提供同一入口。更换立即生效并在重启后保留，不改名字、人设或记忆，也不打断正在进行的对话。

动图按原有帧序循环播放，保留透明度；静态图片沿用轻微身体动作。透明区域穿透点击，普通白底/棋盘格图片不会自动抠图。输入最多 20 MB、1600 万像素，动图最多 120 帧；过大的累计解码量会提示先降低分辨率。静态图最长边压到 1536，动图最长边最多 512，并按帧数限制总像素；极快/极慢帧的时长限制为 20–10000ms，以控制桌面开销。

右下角托盘菜单也能打开面板、切换语音、休眠和退出。关闭面板只是收起窗口，**退出应用请用托盘“退出”**。

## 工作时的行为

- 自动观察鼠标点击、拖拽结束、滚动和停留。默认至少间隔 20 秒，读取鼠标所在显示器的完整画面，按比例缩小到长边最多 1600 像素，并以红圈标记鼠标位置；无须回应时保持安静。不是连续视频录制。
- 在“配置 → 语音与行为 → 观察范围”可选择整块屏幕或鼠标附近（640 × 448）。范围同时作用于自动观察、“看一眼”和附图对话；多显示器时只看鼠标所在的一块。
- 默认玄司停在原地，自动观察不朗读。气泡与角色不会自动抢输入焦点，透明部分穿透点击；角色实体区域用于交互。形象使用透明全身立绘，配有呼吸、思考、回应、休眠和移动的轻微身体动作，尚无眨眼、口型或骨骼动画。
- 手动打开麦克风后才收音，启动和重启不会自动开麦。
- 全屏时隐藏角色、暂停观察及语音并释放模型；退出全屏后恢复角色，语音需再次手动开启。
- 当前景桌面暂不可用时也会暂停；桌面恢复可用后自动显示角色，避免反复读取失败。
- “休眠”取消当前推理、停止收音和播放、卸载模型；可用内存低于 2GB 也会休眠。未对话且麦克风关闭，闲置约 120 秒卸载模型。
- 模型使用较低进程优先级、默认 4 个计算线程和单请求并发。推理会占用资源，不能保证任何负载下完全无影响；玩游戏或运行重任务时可先休眠。
- 其他软件发声时，只显示文字和气泡。朗读前和播放中都会检测；被打断的回复不会稍后补播。声音停止 1.5 秒后，后续回复恢复朗读；检测失效时保持文字模式。

## 日志、配置与快捷对话

面板顶部和托盘右键菜单都有 **配置**、**日志** 入口。

- **日志 → 运行日志**：显示最近 1000 行，支持级别筛选、刷新和自动跟随；隐藏后停止刷新。文件继续按 512KiB 轮转，保留两份备份，不保存聊天或截图正文。
- **配置 → 模型参数与快捷键**：可调 temperature、top_p、回复 token 上限、上下文、CPU 线程和 GPU 层数，也能选择配套 GGUF 文件。保存会结束当前回复并关闭麦克风，下次回应使用新设置。
- **Ctrl+Alt+Space**：唤出鼠标所在显示器右下角的快捷对话框。回车发送，Esc 收起；支持连续语音，与主面板共用当前会话、人设和记忆。可在配置中更换快捷键；冲突或保存失败会保留原来的设置，托盘入口始终可用。

声音回避只读取 Windows 输出设备和应用会话的电平、静音状态，不录制或分析其他软件音频。电平采样间隔约 100ms，设备列表每秒更新，新增会话使用系统通知。突然出现的声音可能短暂重叠，极短提示音、无硬件电平支持的独占音频或设备切换不能承诺零延迟识别。普通播放场景仍需结合实际使用验收；检测异常可在界面和日志看到。

## 模型、数据与边界

图文使用 **Qwen3.5-4B Q4_K_M + 匹配 mmproj**，由本机 llama.cpp CUDA 运行；识别为 **SenseVoice int8**，朗读默认为 **MeloTTS 中英 ONNX**。这是已获授权的功能替代，并非 MiniCPM-o 的原生全双工实现，不能保证各任务的模型质量完全相同。

屏幕文字可能识别错，整屏缩小后的小字和被鼠标标记遮住的文字尤其如此。截图只含当时可见的画面，无法看到被遮挡、最小化的窗口或屏幕之外的内容。它提供陪伴回应，不接管键盘鼠标、不执行模型生成的命令。自动判断语音结束目前采用轻量能量断句，持续环境声或声音太轻时可能误触发/漏触发。

应用只把截图、音频和短期会话放在内存。设置在 `data/settings.json`，长期记忆在 `data/memory.json`，运行日志在 `data/pet.log`；日志不记录聊天/画面正文。长期记忆最多 6000 字，每次按关键词和最近记录选取最多约 700 字，适合偏好与简短事项。清空记忆也会取消当前回复并清掉模型短期上下文；面板中已经显示的文字会在退出时消失。

导入形象的本机副本在 `data/appearances/`，预览导入也会生成副本，相同像素内容会去重。原图片移动或删除不影响已导入形象；恢复默认不会删除以前导入的副本。副本损坏/丢失时暂时显示玄司，可重新选择。素材不上传到云端，不写入 Git；不保留原图 EXIF 和原始路径日志。

记忆文件是本机普通文本 JSON，适合存称呼、偏好等日常资料。应用拒绝明显的密码、密钥、证件和银行卡内容，但关键词过滤不能识别所有秘密，不要把秘密填进去。

推理服务只监听 `127.0.0.1`，带每次随机生成的会话凭据；客户端不使用环境代理。命名管道只用于同一用户重复启动时打开面板。安装脚本会联网下载公开模型，日常代码没有云端请求。测试样例和合成音频在 `data/verification/`，均为人工构造资料，不是用户录音或工作截图。

要更换图文模型，可在“配置 → 模型参数与快捷键”中选择 llama.cpp 支持的 GGUF 与对应视觉组件，保存后在下一次请求加载。模型和视觉组件必须匹配；过大的模型可能显存不足。超长人设/输入会提示缩短，普通长对话会自动移除最早的上下文。

## 维护与验收

本项目是 Python 3.13 + PySide6 原生适配版；初版使用 [NekoAI](https://github.com/nucket/NekoAI) 的猫精灵与动画定义，历史素材和 MIT 许可保留。当前玄司形象来自用户参考图，经图像工具处理及用户授权的本机抠图制作；素材来源见 [形象说明](assets/xuansi/README.md)，不能沿用 NekoAI 的 MIT 标注。来源与各模型许可见 [THIRD_PARTY.md](THIRD_PARTY.md)。初版验收和实际投入见 [验收记录.md](验收记录.md)，后续变更见 [菜单与免打扰验收.md](菜单与免打扰验收.md)、[整屏观察验收.md](整屏观察验收.md) 和 [玄司形象验收.md](玄司形象验收.md)。

当前电脑已安装好依赖和权重，**不必重新安装**。恢复环境时运行 `setup.ps1`；它只创建本目录虚拟环境、下载到指定 D 盘模型目录并生成快捷方式，不设置开机启动。模型及引擎版本与 SHA256 在 `assets-manifest.json` 中。

开发验证：

```powershell
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe -m ruff check pet tests scripts
.venv/Scripts/python.exe -m pet --smoke
```

`scripts/verify_*.py` 分别验证真实图文、语音闭环、长期记忆、原生界面、鼠标观察和资源释放。其中窗口脚本会短暂显示虚拟测试窗口，运行时请先退出桌宠。合成音频验证采用测试播放接收器；真实麦克风、扬声器音色和日常工作流畅度仍需你实际体验。

若无法收音：在偏好选择麦克风，保存后重新开启对话，并检查 Windows 麦克风权限。无声音时先看底部是否显示“其他软件有声音”或“声音检测暂不可用”；声音回避同样适用于试听。安静后用“试听当前音色”检查系统输出设备和音量。若模型报错或明显卡顿，先休眠释放资源，再重试；通过日志菜单查看错误类型。
