# 官网界面设计

2026-10-19 按当前工作区实现核对。共同设计契约为根 [DESIGN.md](../../DESIGN.md)，本页维护官网模块入口、复用关系与实际交互；初版依据及本地截图结果见 [视觉优化验收](验收/视觉优化-2026-10-16.md)，本轮个人空间见 [模块说明](个人空间与历史.md) 与 [验收](验收/个人空间与历史-2026-10-19.md)，不重复维护旧设计记录。

## 目标与信息架构

官网帮助用户认识玄司、确认设备条件并下载；资源平台帮助创作者管理模型、精确版本、作者和许可。主导航为首页、产品、资源库、文档、下载；未登录显示登录/注册，登录后显示昵称与“我的桌宠”。当前公开包来源见 [0.7.1发布验收](../发布与安装/验收/安装包0.7.1发布验收.md)，是否可下载安装以下载页 API 返回的已发布记录和产物为准；本轮个人空间新增尚未部署或纳入该安装包。

首页按角色介绍、三项原则、日常能力、资源库介绍组织。个人空间分为“我的桌宠”（首页、使用历史、收藏）、“上传管理”（我的作品、上传队列）、“账号”（账号设置、会话与授权）。个人首页突出最近同步的形象和使用时间，不伪装实时设备状态；历史区分实际使用与下载。管理员另有用户、资源发布、客户端版本、后台任务和审计入口。业务路由与权限仍由 Go API 控制，不因显示管理菜单而授予权限。

## 页面与组件入口

账号表单使用 [独立身份模块](账号页面.md)：登录主按钮与输入框同宽，密码显隐和找回入口就近显示，注册单独一行，邮件帮助按任务和成功状态出现。局部CSS Module不改变其他页面布局，实际效果与范围见 [验收](验收/账号表单体验-2026-10-19.md)。

2026-10-19 访客流程补齐：公共导航为“首页、产品、资源库、文档、下载”；个人侧栏在身份检查成功后出现，管理侧栏还需管理员权限。访客直接访问私人路由时显示独立登录入口，身份请求失败则保留错误和重试。登录与注册保留原站内目标，退出返回首页。验收见 [访客入口与登录流程](验收/访客入口与登录流程-2026-10-19.md)。

## 视觉与响应式

全局 token 以 globals.css 为准：暖白 `#f7f5ef`、墨黑 `#20231f`、草绿 `#4c654e`、辅助文字 `#5b675a`、淡金 `#9c7b3d`、边框 `#dedfd5`。金色用于少量装饰，首页角色区沿用黑金画框；工作台保持浅色与紧凑信息密度。不使用虚构客户端截图、评价、用户数或下载量。

内容最大宽度 1200px，桌面边距 32px、手机 20px。正文 15px，按钮圆角 6px、面板 8px；标题按屏宽缩放。首页专用布局留在 home.css，共用控件与业务页面使用全局样式，避免一次首页改动形成第二套视觉变量。

640px 及以下主导航折叠、首页单列；资源筛选在 900px 以下两列、640px 以下单列。工作台窄屏导航放到正文上方；共享栅格允许列收缩，表格只在局部容器滚动。目标尺寸为 320/390/768/1024/1440px，并检查 200% 缩放后的操作可达性。

## 交互与可访问性

- 导航用 aria-current 标记当前位置；手机菜单提供 aria-expanded 与 aria-controls，关闭后链接不进入 Tab 顺序。Escape 关闭并把焦点还给按钮；点击链接和路由变化重置展开状态。
- 资源筛选先编辑搜索、类型和标签，点击筛选或 Enter 后提交，并清空游标；翻页保留已提交条件。输入过程不触发查询。标题使用 h2，与列表页 h1 对齐。
- 页面保留加载、空、错误、未登录与权限不足提示；上传进度和后台校验分开显示，结构通过仍提示待客户端试载。错误不能用假资源或虚构成功替代。
- 使用语义化标题、关联表单标签、可见焦点与状态播报；装饰图标对辅助技术隐藏。辅助文字目标对比至少 4.5:1，颜色不能独自表达状态，尊重减少动画偏好。
- 用户操作通过事件处理；查询缓存、请求和表单继续复用现有模块，不用 effect 镜像菜单或筛选派生状态。平台权限与上传契约见 [接口约定](接口约定.md)。
