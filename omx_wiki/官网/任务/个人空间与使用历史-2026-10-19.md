# 个人空间与使用历史

2026-10-19 用户已确认实施：登录后突出“我的桌宠”，补齐形象使用历史、收藏和 AI 模型历史回选；网页导航、代码和文档按模块组织。源码模块见 [个人空间](../个人空间与历史.md) 与 [客户端历史](../../客户端/形象与模型历史.md)，完成情况以 [实际验证记录](../验收/个人空间与历史-2026-10-19.md) 为准。本轮新增尚未纳入公开0.7.1包或线上部署。

## 模块与入口

- 我的桌宠：`/dashboard`，显示用户身份、最近同步的形象、最近使用和收藏入口。同步时间明确可见，不把远端最近记录称为实时设备状态。
- 使用历史：`/dashboard/history`，分“形象使用”“下载记录”，支持分页和删除。下载成功不等于实际使用。
- 收藏：保留 `/dashboard/library`，明确是手动收藏及固定版本。
- 上传管理：保留作品和上传队列的现有路由，作为创作者操作。
- 账号：保留资料、会话和客户端授权；修正原有“客户端仅可读取”的过时说明。
- 前端新增功能分别放入 `features/companion/`、`features/history/` 等独立目录；页面只组装模块，复用现有 UI、API 和 Query，不添加依赖。
- 桌面端：形象历史与 AI 模型历史独立模块；不向既有窗口、运行时或页面持续堆入实现。

## 历史接口契约

所有业务接口沿用 `/api/v1`、camelCase、现有错误 envelope、会话与 CSRF 校验。

`HistoryEntry`：

```ts
type HistoryEntry = {
  id: string;
  kind: "APPEARANCE" | "DOWNLOAD";
  appearanceKind: "DEFAULT" | "MODEL" | "IMAGE" | "ANIMATION" | null;
  resourceId: string | null;
  resourceVersionId: string | null;
  name: string;
  version: string | null;
  occurredAt: string;
  deviceLabel: string;
  available: boolean;
};
```

- `GET /me/history?kind=APPEARANCE|DOWNLOAD&limit=20&cursor=...`：`{data: HistoryEntry[], meta:{nextCursor:string|null}}`。省略 kind 返回两类；默认 20、最大 100，使用稳定的时间/ID 游标。
- `PUT /me/history/{id}`：明确完成使用后同步一条形象历史，客户端生成 UUID 供重试去重。正文为 `kind:"APPEARANCE"`、`appearanceKind`、`resourceId:string|null`、`resourceVersionId:string|null`、`name`、`occurredAt`、`deviceLabel`。成功 204；同 ID 不同内容返回 409。不可由客户端伪造 DOWNLOAD。
- `DELETE /me/history/{id}`：只删除自己的记录，204。
- `DELETE /me/history?kind=...`：清空自己的对应类别，省略 kind 清空全部，204。
- resourceId/versionId 必须同时存在或同时为空；存在时检查版本归属、可读权限和类型，名称及版本以服务端资源为准。已失效资源的旧记录仍可显示，但 `available:false`，不可泄露其他人的私有资源。
- 名称最长 120 字符、设备标签最长 80 字符；时间必须合法且不能明显超前。严格拒绝多余字段，历史接口不接收图片、聊天、屏幕、文件路径、API 地址、密钥或凭据引用。
- 下载历史由下载字节处理器在完整传输成功后写入，使用票据 ID 去重。匿名下载继续可用，无登录用户不写个人历史；申请票据不记成功下载。

## 客户端授权与同步

- OAuth 增加 `history:read`、`history:write`，保留既有 `resources:read` 基础 scope。history:write 必须连同 history:read 申请。
- GET 历史只允许 history:read；PUT/DELETE 只允许 history:write。普通浏览器登录仍按账号隔离。既有 read/write 资源令牌不自动获得历史权限。
- 桌宠默认只在本机记录。用户主动开启形象历史同步后，显式浏览器授权，绑定官网来源和用户 ID；不同账号、不同官网不能混传本机历史。关闭同步后停止上传，本机历史仍可用。
- 未经明确选择，不批量上传开启同步以前的本机记录。失败保留本机记录及可重试状态，不能让网络失败撤销已成功的形象切换。
- 本机历史仅在设置保存与真实试载均成功后追加；下载/预览/失败/回滚不计为实际使用。历史回选复用既有严格预览/应用流程，文件失效明确提示。
- 本机历史有上限，损坏文件保留并报告，原子保存；界面线程不做网络和批量磁盘工作。需要显式移除/清空入口。

## AI 模型历史

AI 模型历史先在本机完成：保存成功的模型配置可回选，当前配置和历史分开显示；加载历史只填写草稿，不绕过验证或直接切换运行中的模型。API 密钥保留 Windows 凭据库，不能以正文进入历史文件或网站。旧凭据引用的生命周期必须与保留的本机历史一致，失效引用应提示重新填写，不能伪装可用。
