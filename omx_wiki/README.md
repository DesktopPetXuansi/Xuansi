## 阅读与维护约定

现行指南描述当前实现，规划记录设计，历史验收保留原阶段的范围、失败、测试数量、耗时和摘要；后续复验单独补录。验收音频、截图、数据库和报告位于本机忽略目录，不保证在新克隆中存在。

原 `方案审核.md`、`实施规格.md`、`菜单与免打扰增量规格.md`、`实时对话规格.md` 的独有内容已合并到 [历史方案与规格](项目/历史方案与规格.md)，不能将草案中的实时能力视为当前承诺。

普通说明文档新增到对应模块，任务和验收放入模块内相应子目录，并同步本页和链接。wiki 技能使用根目录的速记页以及 `index.md`、`log.md`；这些工具入口保留既定位置。

仓库根 [README](../README.md) 保留项目入口。生效范围指令 `AGENTS.md`、依赖锁文件、机器接口契约，以及 [LICENSE](../LICENSE)、[NOTICE](../NOTICE)、[玄司素材许可](../assets/xuansi/LICENSE)、[Neko 素材许可](../assets/neko/LICENSE) 保留在功能或法律要求的位置。
