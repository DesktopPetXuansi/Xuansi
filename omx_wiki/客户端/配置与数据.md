## 默认值与校验范围

设置位于当前应用根目录的 `data/settings.json`，不是全局用户配置目录。未知字段忽略，缺失字段补默认值；值的 Python 类型也严格校验。JSON 无法读取、类型或校验错误时整份回退默认设置，保留原文件，不是逐项纠正损坏值。

| 字段 | 默认值 | 允许范围或含义 |
| --- | --- | --- |

默认人设原文：

> 你是一位温柔、机灵的桌面伙伴，陪我工作和学习。自然地说中文，关心但不过度打扰。

> 回复简短自然，通常一到两句话。看不清或无法确认的事情要直说，不要编造。

修饰键为 Alt、Ctrl、Shift、Meta/Win；Meta 与 Win 等价，不重复计数。合法写法也可能因系统注册冲突失败，程序保留旧绑定。切换 TTS 表单时音色会重置：Kokoro 为 46，Melo 为 0；这与首次启动默认值不同。

## 保存、草稿与本次运行状态

| 操作 | 实际影响 |
| --- | --- |
| 点击“保存全部设置” | 校验模型文件及形象，预注册热键，后台保存成功后应用；关闭麦克风、取消回复并释放模型，清除临时朗读覆盖 |
| 关闭、Esc 或收起控制中心 | 有配置改动时按上述路径自动保存；失败或保存期间又修改草稿时保留窗口 |
| 保存或清空记忆 | 独立于配置表单；取消当前任务并清空短期会话 |
| 应用形象 | 保存形象字段并更新角色及窗口图标，保留当前会话与其他配置草稿 |
| 切换顶部“声音回避” | 持久保存开关，在线调整检测策略，保留当前会话 |
| 对话朗读按钮/自然语言控制 | 本次运行的临时覆盖；重启或普通配置保存恢复已保存偏好 |
| 托盘退出 | 结束应用；不调用控制中心的关闭自动保存，先保存编辑中的草稿 |

人设、语音与行为、模型与快捷键共用一份配置草稿；展开、折叠或定位分区不会提交配置。“保存全部设置”不代替“保存记忆”或“应用形象”。

配置与记忆写入采用同目录临时文件再替换。持久化操作已开始时会等待完成，取消不回滚已保存结果。错误配置原文件保留；修正前不要用默认值覆盖需要恢复的原始文件。

## 数据与生成文件

下表路径以当前项目/安装目录为根。源码版和安装版分别保存，程序不自动迁移；默认模型目录则共用。

| 路径 | 内容与处理 |
| --- | --- |
| `data/settings.json` | 用户设置，普通 JSON |
| `data/memory.json` | `{"notes": "…"}` 格式的未加密长期记忆 |
| `data/appearances/` | 导入形象的规范化 PNG/APNG 副本；预览时即可能生成，恢复默认不删除 |
| `data/pet.log` | 运行状态日志，512KiB 轮转，两个备份 |
| `data/setup.log` | 安装 PowerShell 记录，追加写入，可能包含本机路径 |
| `data/app.lock` | 当前根目录实例锁，不是用户设置 |
| `data/verification/` | 验收工具生成的报告、测试音频、截图等；普通应用不自动生成这一整套证据 |
| `.venv/` | 当前根目录的 Python 环境 |
| `runtime/llama/` 及下载压缩包 | 本地模型服务与运行库 |
| `runtime/python/` | 安装包内置基础 Python；源码环境不一定有此目录 |
| `D:\AI\Models\desktop-pet` | 默认图文和语音模型，独立于应用目录 |
| `build/`、`dist/` | 构建缓存、暂存源码、安装器及摘要清单 |

日常应用在内存处理截图、录音和短期会话，不自动将其正文存盘；日志记录运行状态，不作为聊天历史。**验收脚本会保存合成文字、音频和虚拟窗口截图**，应按脚本说明理解其数据范围。源码仓库通过 [.gitignore](../../.gitignore) 排除本机数据、运行库、模型和环境。

控制中心“运行日志”分区读取当前日志尾部最多 256KiB、1000 行，展开且控制中心显示期间每秒异步刷新，收起分区或控制中心后停止；它不是完整历史日志检索器。需要轮转前记录时查看 `pet.log.1`、`pet.log.2`。

## 记忆限制

总量最多 6000 字；对话追加单条 1–500 字，手动编辑不受单段 500 字限制。重复整行不追加；保存时检查敏感内容，对话保存还检查来源文本。过滤不等于完备的秘密识别或加密。

0.5.6 提供完整候选给模型按 token 容量选择相关原文，每轮最多 700 字，无关时不注入。存储格式未迁移，不存在向量索引或自动总结数据库。损坏 JSON 会保留文件并读作空记忆，需修正后再保存。

## 模型、网络与备份

软件可更换图文 GGUF 和匹配 mmproj，但语音模型根目录仍由源码常量决定，没有全套模型路径设置。修改位置与安装前提见 [安装与发布](../发布与安装/安装与发布.md)。

应用推理客户端只访问本机回环服务，使用临时凭据并禁用环境代理；安装下载器使用外网，不能将这一客户端设置推广为“安装时也禁用代理”。

在退出桌宠后备份 `data/settings.json`、`data/memory.json` 和 `data/appearances/` 可保留配置、记忆及导入形象。换目录时需要自行复制；模型路径及输入设备编号仍需在新环境核对。程序没有自动跨目录迁移或云同步。卸载保留边界见 [安装与发布](../发布与安装/安装与发布.md#升级与卸载)。
