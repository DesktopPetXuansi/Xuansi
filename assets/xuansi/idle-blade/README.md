# 玄司久置拔刀姿态

当前版本入口（2026-10-07）：[0.5.5 发布验收](../../../安装包0.5.5发布验收.md)。发布进度按该记录理解；历史正文的日期、测试、失败、工时及摘要保留。

文档同步：2026-10-07。当前源码与历史版本入口见 [文档索引](../../../文档索引.md)。

这组透明 PNG 用于默认 Live2D 玄司的单次久置待机动作。`reach.png` 抬手够刀柄，`grip.png` 握住刀柄，`draw-half.png` 半拔，`drawn.png` 展示完整拔出的长刀；播放时按相反顺序收刀。

现有 PSD 的身体层合并了双臂。运行时使用全身透明姿态，可以避免单独叠加手臂时留下原手臂重影。姿态显示时清空 GL 缓冲，只显示姿态帧，暂停底层 Live2D 参数更新和绘制；动作结束或用户有键鼠输入后淡出姿态并恢复模型。默认尺寸下四帧缓存约 0.29 MiB，素材只在应用初始化或桌宠尺寸更改时读取和缩放。

2026-10-07 更正：原说明“Live2D 模型本身仍在下层正常更新”对应早期实现，已按当前 [Avatar 入口](../../../pet/avatar.py) 更正；本轮源码拆分后，暂停底层绘制的分支见 [Live2D 绘制](../../../pet/avatar_live2d.py)，姿态与淡出见 [拔刀实现](../../../pet/avatar_idle_blade.py)。暂停底层绘制的修复已包含在 0.5.0 及后续版本，源码拆分纳入 0.5.5。此次默认形象预览不加载拔刀姿态，不会因预览窗口久置自动播放此动作，见 [预览修复验收](../../../形象预览Live2D修复验收.md)。
