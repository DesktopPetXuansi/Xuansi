## 完整交付检查

- [ ] 安装前：检测先于正式写入应用、pip 与权重下载；探测失败有界且可重试，预估不标成实测。
- [ ] 设备：无 Python、无 D 盘、无 NVIDIA、显存被其他程序占用、低内存、磁盘不足和不兼容系统分别有正确路径。
- [ ] 资源：标准、轻量、已勾选备用和 API-only 资源集合正确；匹配投影、完整摘要、安全解压和续传均验证。
- [ ] API：全部目标服务商的具体支持模型、接口和模式明确；只有 `/models` 成功不能算完整兼容。
- [ ] 能力：聊天、合成图像、工具回执续答、记忆人物与否定关系、流式结束、截断和取消分别有证据。
- [ ] 回退：允许链之外不尝试，最多有界切换，已执行写入和动作不重复；鉴权、额度和协议错误分类可见。
- [ ] 数据：用户自备 Key，计费与测试说明清楚；Key 不进命令行、普通配置或日志，API 与官网凭据隔离。
- [ ] 发送范围：后台观察云端截图和云端记忆检索默认关闭；未允许检索时不提供在线检索工具、不发送候选。开启时说明可能分批发送整个候选库，并验证分片、出处校验及最终摘录；未选云端识别不上传录音。
- [ ] 客户端：首选和当前模型分别显示；仅改密钥、保存失败、并发编辑、收起、休眠与退出保持契约。
- [ ] 语音与动画：组件选择、音频拥塞反馈、主动请求优先和资源恢复有验证；不宣称 API 解决全部本机负载。
- [ ] 升级：保留用户配置、记忆、自定义模型和旧目录；配置损坏可恢复，不混入未提交官网或素材工作。
- [ ] 交付：Ruff、编译、完整回归和依赖边界检查通过，原生 Qt、真实模型与隔离安装验收完成；外部测试缺口单独列明。
