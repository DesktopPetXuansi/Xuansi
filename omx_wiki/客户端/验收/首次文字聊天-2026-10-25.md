# 首次文字聊天验收（2026-10-25）

本轮目标是把“完成安装后成功聊上第一句话”接顺。保留安装器、七个主标签、九个固定页面、原模型表单、凭据保存事务和聊天链路；只在对话页增加可收起的使用检查与恢复操作。

## 实现与判定

- `pet/first_chat.py` 连接后台检查、当前请求结果和主线程界面；代次保护覆盖迟到配置检查、保存阻断及旧写入提示。
- `pet/first_chat_card.py` 负责紧凑卡片；展开短标题为恢复按钮留宽度。说明最多预览三行，全文有悬停和辅助描述。
- `pet/first_chat_state.py` 只持久化版本号与成功布尔值。检查不读取密钥、加载模型或请求在线 API；文件存在只显示“待对话确认”。
- `Runtime.chat_succeeded(int)` 只在普通文字聊天得到最终非空正文、请求仍有效时发出，位于 TTS 之前。工具前说明、空回复、取消、试听、失败和服务能力验证不算成功。
- `Runtime.request_issue(int, ConversationIssue)` 提供受控原因及现有设置入口。未知异常不回显任意 URL、邮箱或密钥，401/403 不断言一定是 Key 错误；资源缺失与容量不足保留具体原因。
- 试听组件缺失、临时／已保存静音和声音回避均有提示；中途声音回避不会被当成完整播放。不自动开麦、解除静音或重试可能有写入的请求。
- 模型或密钥有草稿时保留输入、回到模型页，保存成功并确认凭据快照后重查。模型目录初始化失败也进入失败和结束生命周期。

## 原生窗口与真实本地模型

使用新的临时配置、空记忆和独立成功标记，启动原生 Windows Qt 控制中心及真实 Qwen3.5-4B Q4_K_M 本地模型，通过原有输入／发送信号取得非空最终回复，再确认标记内容、引导收起及模型进程释放。运行使用 PySide6 6.11.2，DPR 为 2；没有运行桌面输入监控，没有开启麦克风、朗读或屏幕工具，没有调用在线 API 或读取真实用户配置和记忆。

720×560、520×480、成功收起、恢复操作四张原生 PNG 已人工查看。几何断言同时检查卡片与操作位于视口内、输入／发送完整可见、聊天记录至少 64px、页面无横向或整页纵向滚动。恢复截图的权限错误是明确标注的受控通知注入，不能据此声称真实在线服务已验收。

可复现命令：

```powershell
.\.venv\Scripts\python.exe scripts/verify_first_chat.py `
  --model '<已安装的 Qwen3.5-4B GGUF>' `
  --projector '<配套 mmproj-F16.gguf>' `
  --runtime-root '<含 runtime/llama 的项目根目录>' `
  --output '<独立验收输出目录>'
```

记录存于忽略的 `data/verification/first-chat-2026-10-25/`：`result.json`、隔离日志及四张原尺寸截图。脚本只复用只读模型与计算后端，临时配置和记忆在结束时释放。
