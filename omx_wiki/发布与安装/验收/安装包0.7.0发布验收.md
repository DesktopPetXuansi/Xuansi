# 0.7.0 安装包与本地升级

日期：2026-10-18。用户已明确要求更新 GitHub、本地软件和安装软件。当前阶段：准备构建及隔离安装验证，尚未发布。累计功能包括安装前检测、模型目录/独立语音选择、多模型接入和设置易懂化；历史 0.6.0 标签与资产保留。

## 执行顺序

1. 核对已提交源码、版本和现有安装；从精确提交在干净 worktree 构建，不打包未跟踪的个人制作素材。
2. 固定 Python/Inno 版本与摘要，构建安装器并生成 SHA256SUMS；在隔离目录安装，检查预检、依赖、资源、设置、原生启动与默认 9B 路由。
3. 备份现有安装程序与用户数据后，更新原安装目录；核对设置/记忆摘要、来源提交、快捷方式、卸载登记与启动状态。
4. 普通快进同步 GitHub 源码和新版本标签，先上传发行草稿并重新下载校验，再公开发布并验证匿名下载与 Latest。

## 当前依据与边界

设置改动已有 737 项 Python 回归通过、2 项条件跳过，Ruff/编译与原生布局验证通过，见[设置易懂化验收](../../客户端/验收/设置易懂化-2026-10-18.md)。本页后续补录构建来源、安装结果、摘要和发布状态，不能以源码回归替代完整安装验证。

本机更新保留已有设置、记忆、导入形象及凭据。安装器按向导选择更新模型/语音字段并备份旧设置；本轮在原目录更新后恢复用户的原有选择，并复核字节摘要。不会读取真实 API 密钥或发起真实云端计费测试。

CPU、跨设备、其他服务商与 4B 实验模型的旧缺口继续见[多模型实施验收](../../客户端/验收/安装前适配与多模型-2026-10-18.md)。不把本机默认 9B 的通过推广为全部路线保证。
