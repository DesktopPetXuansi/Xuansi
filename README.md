# 玄司 Xuansi · 本地 AI 桌宠

玄司是运行在 Windows 上的桌面 AI 伙伴，支持屏幕理解、文字聊天、连续语音、长期记忆和 Live2D 形象。可选本机模型或自备 API 密钥的在线服务；本机对话无需云端账号，在线调用由服务商直接计费。名字、人设、声音和形象可在软件中调整。

## 版本与发布

0.9.0 新增首次文字聊天检查、可操作的失败恢复和软件内反馈中心。保留形象一键使用、本机形象／AI配置历史及原有模型设置；模型、Key、语音和形象可逐步配置。实际版本及来源以安装目录 `release.json` 和 [GitHub v0.9.0](https://github.com/DesktopPetXuansi/Xuansi/releases/tag/v0.9.0) 为准。发行来源和旧验收按[历史索引](docs/context/history/README.md)查阅。

当前开发源码中的屏幕权限与在线记忆权限独立设置，均默认关闭。4B 模型仍为实验选项，已有语义验收失败，不作为完整自动备用；CPU、其他服务商和跨设备能力仍有实测缺口。具体证据与已知限制见[风险与验证缺口](docs/context/RISKS.md#模型与设备验证)。历史 0.6.0 的构建与发行身份按[历史索引](docs/context/history/README.md)查阅。

在“更换形象 → 在线挑选 / 我的形象”选中后点击“使用这个形象”，软件会自动下载或复用完整副本、检查并切换，预览可选，失败保留原形象。形象历史同步默认关闭，开启后还需账号授权和支持新接口的网站；本次客户端发行不等于服务器已部署。资源管理与上传分享继续为页内入口，旧标签、安装包和已提交的验收按[历史索引](docs/context/history/README.md)查阅。

## 已实现能力

- 屏幕理解（当前开发源码）：在对话页开启按轮分享，再点「看一眼屏幕」或为下一条文字／语音附一张图。默认范围为鼠标附近，可在「语音与行为」改为鼠标所在显示器。在线发送前逐轮确认服务商、模型和范围。关闭分享会停止当前涉图回复，保留麦克风选择。图片和画面派生回复只供本轮推理，想长期保存的信息可另用文字明确提出。
- 聊天与记忆：本地图文对话、近期会话上下文。可明确要求保存记忆，也可在「长期记忆」选择条目，更正、撤销更正或彻底遗忘。遗忘会清除该条目的旧修订和当前推理上下文，已显示的聊天仍可查看。
- 连续语音：手动启麦、实时转写、话段结束后生成并分段朗读。提交后暂停收音，回复处理及播放完成再恢复；不支持全双工口头插话。
- 角色动画：默认 Live2D 眨眼、视线、响度口型及发丝衣摆摆动；直接动作请求目前只开放一次眨眼。当前本地开发源码中，固定目录的本机 9B 模型可选择让默认形象用眼睑配合回复语气，其他模型或形象保持平静；满足空闲条件后播放预制拔刀姿态。
- 主动消息（当前开发源码）：可在「语音与行为」开启本机短问候，也可在对话页开启仅本次运行的本机自动观察。两者默认关闭，共用每小时一次、每天两次的限额。「主动消息静默」可暂停一小时或到当天结束，仍可主动发起对话。
- 形象替换：在“在线挑选”或“我的形象”选中后可直接使用，独立预览可选；本地导入图片、动图或导出的Live2D运行模型后点击使用。成功自动保存，失败保留原形象，更换无需先上传。旧版0.7.1仍需先下载并预览。
- 使用历史：本机保存已成功使用的形象和 AI 配置，方便回选；形象历史只有主动开启同步并授权账号后才发送。AI 配置历史留在本机，不上传 API 密钥或对话内容。
- 反馈中心（0.9.0）：控制中心底部或托盘可填写问题与建议，无需登录；版本信息自选附带，失败保留草稿。接收网站需部署配套接口，已随0.9.0正式包交付，公开0.8.0包保留原样。
- 桌面控制：对话、设置、记忆、更换形象及日志集中在同一控制窗口，通过七个横向主标签切换；官网资源与上传保留在形象页的次要入口，沿用暖白和草绿配色。角色点击、托盘和快捷键打开同一窗口；顶部提供连续对话和休眠，对话页提供朗读、看屏幕、停止回复及声音回避；启动不自动开启麦克风。
- 官网资源：在控制中心连接官网账号，直接选择本地 Live2D 模型文件夹或入口文件上传，自动整理、校验与加入资源库；也支持资源下载安装及离线使用。

客户端入口及模块位置见[项目映射](docs/context/MAP.md#桌面客户端)。

## 下载与安装

从 [GitHub v0.9.0](https://github.com/DesktopPetXuansi/Xuansi/releases/tag/v0.9.0) 获取 Windows x64 在线安装包与 `SHA256SUMS.txt`。安装包内置 Python 3.13.15，无需预装 Python 或 Git；上文标注“当前本地开发源码”的情感对话功能仍在验证，尚未提交到公开主线或随该安装包发布。

安装器支持 **Windows 10 1809 及以上 x64**，安装前会评估系统、内存及磁盘，并允许选择模型目录。仅使用在线服务时不要求 NVIDIA 显卡、本机模型或 D 盘；本机加速按实际设备选择，CPU 路线尚未完成真实设备验收。标准 9B 权重和看图组件约 6.60 GB，语音、环境与引擎另计。首次安装需要联网，资源和临时空间以向导预检为准，资源估算不保证实际回复速度。

安装完成后从开始菜单“玄司 AI 桌宠”启动。升级前从托盘退出旧实例，选择原安装目录；记忆、人设和导入形象保留，模型与语音字段按向导选择更新，旧配置另存为 `data/settings.before-install-*.json`。程序没有自动更新或跨目录数据迁移，来源可查看安装目录的 `release.json`。

安装前请阅读[安装须知](installer/安装须知.txt)，开发及安装验证入口见[操作手册](docs/context/RUNBOOK.md#桌面客户端开发)。

## 从源码运行

准备 Git 和 64 位 Python 3.13，执行：

```powershell
git clone https://github.com/DesktopPetXuansi/Xuansi.git
cd Xuansi
py -3.13 --version
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
.\.venv\Scripts\pythonw.exe -m pet
```

未传安装计划时，脚本仍创建项目内 `.venv` 并下载全套本地及语音资源，包括 Kokoro；不设置开机启动。新源码默认识别旧 D 盘模型目录，其他情况使用 `%LOCALAPPDATA%/Xuansi/models`。API-only 和按选项部署通过安装计划执行，详见 [安装与验证入口](docs/context/RUNBOOK.md#桌面客户端开发)。
