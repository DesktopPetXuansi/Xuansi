制作模式：内置 `imagegen` 参考图编辑，两轮后仍得到 RGB 棋盘背景。用户明确回复“允许，使用本机脚本抠图”，再用 `scripts/prepare_xuansi_sprite.py` 本地移除背景。最终 PNG 的 alpha 极值为 0 和 255，不是把棋盘当作透明。当前素材经图像工具重新绘制，并非原图逐像素裁剪。

第一轮提示词要点：忠实提取参考图最左侧正面全身角色；保留黑发高马尾、金棕眼、黑金古风衣服、发饰和可爱比例；完整保留发梢和鞋子；去掉文字、其他视图、色卡、背景及投影；只留一个居中角色，要求真正透明 alpha。

最后一轮编辑提示词要点：只修背景，角色完全保持不变，清除画出的棋盘格，输出 alpha=0 的真实透明背景，不要把棋盘画进图片。该轮未产生 alpha，因此最终透明通道由授权的本机脚本完成。

本机处理可重跑：`.venv/Scripts/python.exe scripts/prepare_xuansi_sprite.py <第二轮输出.png> assets/xuansi`。该脚本按此素材的中性棋盘背景和头像坐标设计，不是通用抠图工具。
