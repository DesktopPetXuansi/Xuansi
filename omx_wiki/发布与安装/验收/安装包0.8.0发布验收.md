# 0.8.0 安装包与同步验收

日期：2026-10-19。用户已要求更新 GitHub、安装包与本机软件。本页记录本次发行；构建前状态为准备中，完成后补录精确来源和实测结果，不将源码预览当作正式安装。

## 发行范围

形象一键使用、完整缓存复用、失败恢复及本机形象/AI 配置历史。官网个人空间、访客流程和分步帮助纳入源码；服务器部署是独立操作，本次不自动执行。

历史同步默认关闭，须用户开启、账号独立授权和网站支持。旧网站缺少端点时会提示同步失败并保留本机待同步记录，不影响本机形象使用。AI 配置历史不上传，安装包不包含用户配置、凭据、记忆、开发环境或未跟踪素材。

## 验证与发布步骤

- 在干净的 `codex/release-0.8.0` 工作树冻结版本，只从 Git 提交导出。
- 运行源码回归、静态检查、官网构建与后端回归，完成有界独立审查。
- 构建固定工具链安装器，核对静态载荷与源提交，隔离安装和本机升级后验证原生形象流程。
- 先上传草稿并下载核对，再发布并验证匿名下载、Latest 和旧版资产。
- 本机升级前备份程序和用户数据，升级后验证用户 JSON 摘要不变。

本机忽略目录 `data/verification/release-0.8.0-2026-10-19/` 保存命令结果、JUnit、安装、文件摘要和公开下载报告；构建位于 `build/release-0.8.0/`。本地日志和数据不上传到公开 Release。
