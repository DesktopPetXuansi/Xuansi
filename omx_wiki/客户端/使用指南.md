# 使用指南

本页集中说明客户端操作、资源上传和故障处理。配置字段见 [配置与数据](配置与数据.md)，内部流程见 [架构说明](../项目/项目文档.md)。

当前源码使用紧凑控制中心，界面契约见 [界面设计](界面设计.md)，2026-10-16 的实际验证范围见 [界面优化验收](验收/界面优化-2026-10-16.md)。文档描述源码行为，不据此认定公开安装包已更新。

截至 **2026-10-18**，本地源码另已接入模型策略、在线 API 与独立资料发送授权。DeepSeek Flash 非思考模式已通过[真实合成能力与生产冒烟](验收/DeepSeek真实接口-2026-10-18.md)，其他服务商仍未实测。这些能力以当前源码为准，预设不代表全部实网兼容；成品不附带测试 Key，用户仍需配置自己的凭据。已发布 0.6.0 按历史记录理解。设计入口见[方案](../发布与安装/安装前适配与多模型方案.md)，完整证据和缺口见[多模型验收](验收/安装前适配与多模型-2026-10-18.md)。

## 打开、保存与退出

点击角色、双击托盘或选择托盘“打开控制中心”，都会打开同一个控制窗口；拖动角色调整桌宠位置。默认 `Ctrl+Alt+Space` 打开控制中心并切到“对话”标签；窗口已激活时再按一次会尝试保存配置并收起。

控制中心沿用暖白和草绿配色，顶部使用浏览器式横向标签栏：对话、人设、记忆、语音与行为、模型设置、桌宠形象、官网资源、模型上传、运行日志；内容页头显示完整功能名称。每次显示一个功能页，切换复用原有控件、配置草稿和各页滚动位置，不会另开控制窗口。未应用的形象候选也会保留；若已应用的形象发生变化，预览会同步新形象。

窗口较窄时，用标签栏左右滚动按钮进入目标页；`Ctrl+Tab`向后切换，`Ctrl+Shift+Tab`向前切换，首尾循环。标签下方保留运行状态、连续对话与休眠；对话页输入附近放置朗读、看一眼屏幕、停止回复和“有其他声音时暂停朗读”。记录随窗口伸展，520×480最小窗口也可直接输入和发送。托盘保留“打开控制中心”“休眠/唤醒”“退出”三项。

底部“保存设置”统一保存人设、语音与行为、模型与快捷键，旁边显示保存状态以及本机可用内存/麦克风状态。点击“收起”、关闭窗口或按Esc时，这些配置有改动才自动保存并结束当前回复、关闭麦克风，成功后收起；无改动时直接收起。输入无效、写入失败或保存期间又修改了草稿，会保留窗口。长期记忆另需点击“保存记忆”，形象另需点击“应用形象”。完全退出使用托盘“退出”；退出路径不等同于关闭控制中心的自动保存，退出前先保存正在编辑的草稿。

官网资源操作进行时，底栏显示相应进度，切到其他标签后仍能看到；悬停可同时查看本机资源信息。操作结束后恢复内存/麦克风状态，定时资源刷新不会覆盖正在显示的操作进度。

本地新源码还在底栏持续显示实际使用的本地／在线模型，资源回退时显示原因；该状态与用户保存的首选分别展示，不会被内存轮询或上传进度抹掉。在线且未允许云端记忆检索时，底栏会明确提示未启用。

同一目录重复启动会通知已有面板。源码版与安装版按各自目录隔离配置和实例，不自动迁移数据；不要把启动另一个入口当成升级正在运行的进程。

## 模型与在线 API（本地未发行源码）

在“模型设置”选择“本机运行”“本机优先，在线备用”或“在线优先”，页面只显示相关的常用配置。选择本机后，用“检测电脑并推荐”查看资源估算建议；检测不会替换已有参数，未确认的设备和实验模型不会被标成可靠推荐。选择在线后，依次选择服务商、填写“API 密钥”、点击“测试可用性”，测试成功后再保存。

“高级设置”默认收起，包含自定义 API 地址、模型名称、地区、工作模式、能力声明、模型目录、备用文件、temperature/top_p/token 与 CPU/GPU 参数；不知道用途时保留原值。展开/收起保留所有草稿和当前测试。token 是模型计量单位，不等于中文字数。已有手动配置不会在初始化或模式切换时被默认值覆盖。

本机运行不使用在线候选；本机优先仅允许具有匹配完整能力验证证据的在线配置自动备用；在线优先可以先尝试基础文字对话，尚未验证的图片和工具能力不会因此开启。鉴权、额度、协议错误及用户取消不会被当作资源不足盲目切换。已经返回有效回复或开始工具处理后，本轮不重放至另一模型。

本地主模型可选标准 9B 或轻量 4B；轻量档仍标记业务待验证，不因有下载文件就宣称能力等同标准档。修改档位或模型根目录会更新下方配套 GGUF 与投影路径，初始化保留已有自定义路径。备用路径只填写已安装的配套资源，且备用候选仍受目录中的业务验证状态约束；对话期间不会自动下载。重新检测在后台进行，未知或待验证不显示为实测推荐。

当前源码优先识别已有 `D:/AI/Models/desktop-pet`；不存在时默认使用 `%LOCALAPPDATA%/Xuansi/models`，无需 D 盘。模型根目录同时用于图文和语音资源；移动目录后仍需检查实际文件与主模型配套路径。计算后端可选自动、CUDA、CPU；GPU 层数 99 使用自动分配与 fit 余量目标，0 使用 CPU，1–98 保留手动层数。资源预估不保证响应速度。仅本地和本地优先保存时检查主 GGUF 与投影存在，优先在线不强制要求本地权重。

选择服务商后会自动填写接口参数；自定义服务在高级设置中填写。密钥旁提供“获取 API 密钥（官方）”链接，百炼需核对密钥与接口地区一致。API 使用你自备的密钥，由相应服务商直接计费；“测试可用性”可能产生少量调用费用。结果分别列出已通过与未验证的能力，不代表所有桌宠操作都一定正确。测试只发送示例资料，不读取真实屏幕、录音或记忆；取消与切走／隐藏页面会停止本次测试，不能保证服务商撤销已经产生的费用。结果只适用于对应服务商、地区、端点、模型、模式、上下文预算、能力声明和凭据引用，更换配置或密钥后需要重新测试。

Key 以密码框中的内存草稿保留，保存时写入独立的 Windows 凭据管理器命名空间；普通设置仅保存引用。留空保留当前端点已保存的 Key，修改端点不会复用旧服务商凭据。仅修改 Key 也会显示未保存。保存失败保留草稿；保存期间继续编辑时，只清除与成功快照完全一致的密码草稿，新的模型或 Key 编辑仍可继续保存。清空尚未保存的新 Key 会恢复匹配当前端点的已保存引用，不把验证过但未落盘的引用当作已保存凭据。

“允许在线服务读取长期记忆”和“允许自动观察时向在线服务发送屏幕截图”分别默认关闭，均不由回退策略自动授权。在线普通对话会发送文字、必要历史和工具结果；明确附图会交给当前模型，取消附图仍不等于禁用按需截图工具。未允许云端记忆检索时，不向在线模型提供记忆查询工具，也不发送候选；开启后可能按容量分批发送整个本地记忆库的候选内容，并非只上传最终命中摘录。记忆文件和新记忆写入仍在本机，录音仍采用本地识别。

## 资源压力与恢复

可用内存低于 4GiB 时，后台自动观察间隔暂时增至所保存数值的三倍，空闲角色渲染降低频率；到至少 5GiB 才恢复，避免反复切换。主动提问优先；低于 2GiB 则自动休眠。这些是调度阈值，不是跨设备的最低配置或性能保证。模型闲置约 120 秒且没有忙碌任务或收音时会卸载，下次请求需要重新准备。

全屏、锁屏或桌面不可用时暂停观察与对话并释放模型；清醒状态下连续对话会被关闭，恢复桌面后需手动开启。主动休眠则保留之前的开启选择，唤醒且桌面可用后恢复。收音发生拥塞会丢弃不完整话段并显示状态，不能把丢失部分当作完整原话发送。

## 文字与屏幕提问

切到“对话”标签，输入并发送文字。勾选“这次对话附上屏幕画面”直接附图；“看一眼”直接提交一次看图提问。未勾选时，文字和语音仍可能由模型按需调用截图工具。新请求取消上一轮生成和播放，“停止回复”结束本轮并保留原已开启的连续对话选择。

用户原话、人设、系统提示词、近期会话和工具说明一起交给模型，由模型直接回答或选择截图、查询记忆等工具；工具结果交回后继续回答，不再每轮先做控制分类或强制读取记忆。每次模型响应完整后显示原始正文，工具前的说明也保留；只有本轮最终答复进入分段朗读，工具过程文字不朗读。空回复、生成或音频失败会留下本次运行内可查看的系统提示。

附图、画面内文字和查到的记忆都只是待分析资料，不表示你授权保存、关闭声音或执行动作；原话与这些资料分别交给模型。历史候选曾把动作赞美误当操作请求；各轮失败、分组复验和已知差异见[候选验收记录](../归档/对话与记忆/验收/模型自主工具对话候选验收-2026-10-16.md)。

自动观察由点击、拖拽结束、滚动和停留触发，默认至少间隔 20 秒；忙于对话、收音、休眠、全屏和桌面不可用时不观察。默认整块显示器，偏好中可切为鼠标附近；一次不读取全部多显示器，也不是持续视频录制。

自动观察没有值得评论的内容时，可通过结束观察工具安静结束。程序不再要求模型输出“无需回应”，也不匹配正文关键词删除内容；如果模型仍生成这句话，会原样显示。观察不能保存记忆、改变持续朗读状态或执行角色动作。

自动观察使用触发事件位置。手动“看一眼”、附图文字和语音使用最近有效的外部鼠标事件位置；本应用内操作不更新，单纯移动也不会立即更新。多屏提问前先在目标外部窗口产生有效鼠标操作，避免误以为截图始终跟随当前光标。整屏缩放到长边最多 1600，局部约 640 × 448；遮挡、最小化和画面外内容无法读取，小字也可能看不清。

## 连续语音

点击“开启连续对话”，默认实时模式等待“实时聆听中”再说话。启动与重启都不自动启麦；保存普通配置后需要重新开启。在“语音与行为”通过“使用的麦克风”选择设备，关闭“边说边显示文字，说完再回复”可切为 SenseVoice 整句模式。

当前源码按安装时的语音组件选择显示可用入口：未安装朗读组件时禁用朗读偏好、引擎、音色、速度与试听。只安装实时识别或整句识别时固定使用对应模式，仍可选择麦克风；两种识别均安装时才可切换并保留原偏好。没有识别组件时禁用设备与模式设置。运行时开启缺失组件会显示原因。API 对话不自动安装语音资源，也不自动开启麦克风。

实时模式边说边显示临时转写，较长内容最多预览三行，悬停可查看全文；关闭连续对话或休眠会清空预览及提示。普通音量约0.4秒、轻声约0.8秒无新语音证据后结束话段，实际还受转写分块影响。整句模式约0.8秒静音结束，最长约12秒切句。中间识别不触发回复或记忆；空识别只显示状态并继续听，杂声若被转为非空文字仍可能触发回答。

话段提交后，识别后处理、模型生成、按需工具执行和播放期间都暂停收音，完成后再恢复。即使关闭朗读，模型思考期间也不接收口头插话；文字新请求或“停止回复”可以中断当前轮次。关闭连续对话停止相应收音和语音流程。

0.6.0 由 Qwen 结合原话和近期对话，在同一对话流程内按需调用截图工具；明确勾选时直接附图。**取消勾选不能禁止模型截图，改用文字也不能规避这一点**；当前没有独立禁用截图工具的开关。截图仍限于最近有效外部事件的位置与当前范围。公开 0.5.6 的前置附图判断及更早关键词规则仅作为 [历史版本差异](../归档/文档维护/整理与核对记录.md#record-2abda6e8-实现差异) 保留。

## 朗读、试听与避免声音重叠

对话页输入附近的朗读按钮可切换本次运行状态，也可直接请求“暂时不要读出来”或“恢复朗读”，由模型理解意图。静音保留连续对话的开启选择；重启或保存普通配置后恢复已保存的“默认朗读对话回复”偏好。

关闭朗读只影响声音，仍可正常文字聊天，不需要为文字回复重新开声音。模型可以自主选择读取资料、本轮引擎或结束后台观察；保存记忆、持续朗读开关和角色动作则要求本轮明确的操作请求。这个要求不等于模型理解已经没有误差。

“试听当前音色”读取当前语音表单草稿，同时遵守对话朗读偏好、本次运行开关和声音回避。静音时试听没有声音，不能据此认定声卡故障。默认 Melo 只有音色 0；切换到 Kokoro 时表单重置到 46，范围为 0–102，再切回 Melo 重置到 0。

0.6.0 默认使用 Melo，模型可按需调用工具为本轮选择 Kokoro，提示约定纯英文使用 Kokoro、中文或混合语言使用 Melo；已知纯英文有时仍沿用 fast，显式 Kokoro 偏好保持。工具结果确认、最终正文完整生成后才开始分段合成播放，首音可能比旧流程更晚。自动选择 Kokoro 加载失败回退 Melo，合成生成错误继续反馈。观察沿用独立朗读偏好并在最终答复后分段合成；试听直接使用当前表单选择，清理后的输入最多取前 240 字符，不另做模型分类。

“有其他声音时暂停朗读”默认开启，通过对话页输入附近的同名开关切换并自动保存，勾选表示开启。检测其他软件发声后停止或跳过朗读，文字和气泡保留，本轮音频不补播。安静约1.5秒后下一轮才可能恢复；检测不可用或过期也保持文字。开关不影响麦克风或当前会话。

检测查询输出端点和应用会话电平，不录制其他软件声音。约 100ms 采样，设备切换、极短提示音或特殊独占设备不能保证零重叠。

## 长期记忆

明确说出需要保存的事项，或请求“把刚才这些记下来”；模型结合近期上下文决定是否调用保存工具，不再另做固定授权分类。提示要求含糊时先询问，普通偏好陈述、引用和否定不表示保存授权，但目前真实模型仍有误判，不能承诺所有表达均正确。程序验证工具参数、长度和敏感资料等执行边界，实际保存后才返回成功结果。也可在“记忆”标签直接编辑、保存、清空。

总量最多 6000 字；对话新增单条 1–500 字，手动编辑没有单段 500 字限制。完全重复的整行不追加。只有模型调用查询工具时才读取长期记忆，再从原文选择最多 700 字相关内容，无关时返回空结果，不按最近记录兜底。普通闲聊可以不查询记忆。

记忆保存后重启可恢复；设计上仅在用户要求时保存，不自动总结全部聊天。手动保存或清空会取消当前任务并清掉短期上下文。敏感内容过滤仍存在，不能当作完整秘密检测；记忆是未加密 JSON。持久化写入已经开始时，取消会等待写入完成，不撤回已保存内容；成功或失败收据留在会话上下文，防止模型因丢失结果而重复操作。

## 形象与预览

在控制中心切到“桌宠形象”标签，选择本地图片并预览，再点击“应用形象”。导入预览阶段已生成本机副本，应用才保存配置；原文件移动后仍可使用。恢复默认不删除已有副本。“返回对话”只切回对话标签；应用形象仍需明确点击“应用形象”。按规范化编码结果的 SHA256 去重，不保证任意相同像素的不同编码必然去重。

| 输入/处理 | 当前限制 |
| --- | --- |
| 格式 | PNG/APNG、JPEG、BMP、GIF、WebP；静态或动画由解码结果决定 |
| 文件与画布 | 最多 20MiB，单帧最多 1600 万像素；拒绝 UNC 路径 |
| 静态副本 | 按 alpha 裁边，长边最多 1536，去元数据，保存 PNG |
| 动图输入 | 最多 120 帧，累计原始解码最多 1.6 亿像素 |
| 动图副本 | 长边最多 512，累计最多 1200 万像素，保存 APNG 并循环 |
| 动图时长 | 每帧钳制为 20–10000ms |
| 可点击性 | 完全透明或过淡、所有像素 alpha 均低于 128 的素材拒绝 |

如需透明背景，源图应有真实透明通道；白底和画出来的棋盘不会自动移除。不透明图片也可导入。静态图沿用轻微身体动画，动图保留自身帧序及时长，不自动生成 Live2D、眼睛或口型绑定。缺失或损坏时回退默认形象。

默认候选使用独立 Live2D，显示眨眼、视线和发丝衣摆；“预览眨眼”只驱动候选，不应用、不写配置、不影响桌宠。导入图或模型加载失败时禁用按钮；失败回退 PNG，切到其他标签后再返回“桌宠形象”可重试。预览不接 TTS 口型、不加载久置拔刀。素材与绑定细节见 [Live2D 制作规格](../Live2D与形象/Live2D玄司制作规格.md)。

## 官网资源与本地上传

切到“官网资源”标签可连接账号、查看资源、下载并应用模型、动作和表情；官网地址也在此修改。切到“模型上传”，点击“选择并上传本地模型”，或从“官网资源”点击上传入口，都会在同一控制中心显示上传表单，页头为“上传本地 Live2D”。首次连接仍需系统浏览器登录授权，选择模型时仍使用文件选择器。具体步骤见下方“上传步骤”。

切换标签或收起控制中心不会取消资源上传；点击“取消操作”才会停止当前任务。相同官网地址下重新进入上传会保留表单及入库恢复状态；空闲时“返回对话”只切换标签。完整退出会协调后台任务结束，本机入库恢复状态不跨进程保留。切到“运行日志”可查看当前日志，切走或收起控制中心后停止刷新；离开“桌宠形象”也会停止其动态预览。界面验证范围见 [控制中心合并验收](../归档/客户端/控制中心验收.md#record-ea27e9df)。

### 上传步骤

1. 在顶部切到 **模型上传** 标签，点击 **选择并上传本地模型**；也可在 **官网资源** 标签点击上传入口。上传表单会显示在同一控制中心内，页头为“上传本地 Live2D”。首次连接时，在系统浏览器中登录已验证邮箱的官网账号，点击 **允许上传模型**，再回到控制中心。授权有效期间，后续上传会复用连接。
2. 点击 **选择模型文件夹**，或点击 **选择模型文件**，通过系统文件选择器选取文件夹或 `.model3.json`。模型文件夹有多个入口时，直接选择需要上传的入口文件。
3. 名称、作者、版本号和许可已经预填。作者默认使用当前账号的显示名称，版本默认为 `1.0.0`；请按模型的实际原作者和许可核对，需要时修改。
4. 点击 **上传模型**。客户端自动收集运行文件、整理上传包、创建资源与版本、上传、等待校验，并将完成版本加入自己的资源库。
5. 完成后可以点击 **在官网查看**，或者返回官网资源库刷新，下载并应用模型。

本机官网默认地址为 `http://localhost:3000`，可在控制中心“官网资源”标签修改；公网连接使用HTTPS。账号注册和邮箱验证只需按官网流程完成，验证使用邮件链接。

### 文件与进度

选择模型目录即可，客户端不会把整个目录压缩上传。它只读取入口以及明确的 `Moc`、`Textures`、`Physics`、`Pose`、`DisplayInfo`、`UserData`、动作与表情文件、动作声音引用，保留相对目录。编辑工程、私人笔记和未知元数据声明的附件不会被收集。只有 `.cmo3` 编辑工程时，仍需先在 Cubism 中导出运行文件；客户端不替代模型编辑器。

缺少引用文件、路径越界、模型入口或引用文件为链接、目录中有多个模型入口、文件总大小超过512 MiB时，整理阶段会停止并显示说明；源文件不会被修改。Windows目录链接不会被递归用于寻找模型入口。

上传页显示整理、上传、官网校验与入库进度，期间桌宠界面保持响应。切换标签或收起控制中心不会取消任务；切回“模型上传”可继续查看进度。点击 **取消操作** 可停止正在处理的任务；未完成上传会取消并释放预留空间，临时包在文件线程退场后清理。已经校验完成的官网版本会保留。

若最后加入资源库失败，上传页保留已上传版本，按钮变为 **完成加入资源库**。重试会操作同一个资源，不再创建资源或重传模型；可重新连接原账号后继续。相同官网地址下，切换标签后再返回会复用表单、连接和入库恢复状态；切换官网地址后再次进入上传，会新建上传表单。空闲时点击 **返回对话** 只切换标签。整个客户端退出时会协调后台任务结束，本机恢复状态不持久化，可在官网“我的资源”中查看已上传版本。

### 连接权限

连接复用官网浏览器登录、PKCE随机回环回调和Windows凭据管理器。密码由浏览器提交，客户端不保存密码；令牌不写入设置、日志或测试报告。上传时明确申请本人资源写权限，原有只读授权保持只读，且可从官网“会话与授权”撤销。

流式上传到外部对象存储时只使用服务端提供的限时上传地址，官网Bearer和Cookie不会转发。官网校验通过表示资源包结构完整，实际模型兼容性仍需客户端试载。

## 休眠与空闲动作

休眠取消推理、停止播放、暂停收音并卸载模型，保留原连续对话选择；唤醒且桌面可用时恢复。休眠期间主动关闭后保持关闭；从休眠发送文字会先处理当前回复，再恢复收音。

清醒时遇到全屏、锁屏或桌面不可用，会关闭连续对话并隐藏角色、释放模型；桌面恢复后需手动启麦。可用内存低于 2GiB 自动休眠，无对话及收音时闲置约 120 秒卸载模型。推理仍占计算和显存，重负载时可手动休眠。

久置拔刀要求连续五分钟没有系统键鼠输入，且持续满足默认 Live2D、idle、桌面可用、无忙碌任务和无收音等条件；资格中断会重置。使用预制全身姿态帧，暂停底层 Live2D 绘制；有新输入时淡出恢复。它不是模型可调用的原生抬手动作。

## 故障排查

### 安装与下载失败

已发布 0.6.0 的安装排查先核对 Windows x64、Python 3.13 位数（源码环境）、旧 D 盘资源目录、空间和下载网络；2026-10-18 本地新源码改用可选模型目录，API-only 不要求 D 盘或本地 GGUF，这不表示新的正式安装包已经交付。在线安装器“程序文件已保存”不等于依赖成功，失败提示对应脚本非零退出。

普通网络中断可重新运行安装器或开始菜单“重新下载依赖与模型”；源码版重跑 `setup.ps1`。正式文件摘要正确会复用，`.part` 可续传。摘要或 Range 起点反复失败时，先按日志确认具体资源并保留失败信息，移走对应损坏的 `.part` 或缓存文件后再下载；脚本不会自动清除任意坏缓存。不要通过跳过 SHA256 检查启用错误模型。

已有 `.venv` 若不是 64 位 Python 3.13，`-PythonPath` 不会强制重建它。退出应用后将旧环境移到备份位置，再用正确解释器创建；设置、记忆位于 `data/`，无需为此删除。来源与校验范围见 [安装与发布](../发布与安装/安装与发布.md#下载版本与校验覆盖)。

### 模型不存在或不能加载

升级保留已有模型路径，不会自动改用 9B；本地模式请在“模型设置”选择 GGUF 与匹配投影并保存。检查文件是否存在、是否配套，以及 `runtime/llama/` 的下载/解压是否完成。已发布 0.6.0 的语音根目录固定；本地新源码改用模型根目录设置，优先在线保存不要求 GGUF。任意 Hugging Face 模型并不都兼容当前 llama.cpp 构建。

CUDA 或显存错误时先休眠释放资源，再核对驱动、模型大小、上下文和 GPU 层数。减少上下文或 GPU 卸载量会影响能力及速度；不保证修改某个数值就能解决所有设备问题。具体默认值见 [配置与数据](配置与数据.md)。

### 没有收音或没有回复

1. 确认已手动开启连续对话。默认实时模式等“实时聆听中”再说话；启动不自动启麦。
2. 在 Windows 检查麦克风权限、输入设备及音量，在偏好中选设备并保存，再重新启麦。
3. 看临时转写、状态栏和聊天中的系统提示。空识别只提示继续听；没有文字时优先排查输入。
4. 话段提交后，模型判断、生成及朗读都暂停收音，等回复结束再说；模型思考时没有口头插话功能。
5. 全屏/锁屏后从清醒状态恢复，或保存普通配置后，需重新开启连续对话。休眠则保留原选择，唤醒且桌面可用后恢复。
6. 长时间等待可“停止回复”后重发。缺实时模型文件时补齐所选组件；已同时安装两种识别时，也可关闭“实时识别”切为 SenseVoice 整句模式。

杂声被识别为空白时不提交；被识别为非空文字仍可能触发回复。轻声、持续噪声和设备缓冲会影响结束判断，当前没有按字数丢弃所有短句的规则。

### 有文字但没有声音

先确认朗读按钮及“默认朗读对话回复”偏好；本次运行的静音覆盖也可能来自先前的模型指令。恢复朗读后再检查输出设备和系统音量。

开启“有其他声音时暂停朗读”后，其他软件发声、检测不可用或状态过期都会阻止朗读；安静后不会补播旧轮次。可在对话页关闭此开关后发一个新请求，或安静约 1.5 秒后再试听。试听读取当前表单草稿，同样受朗读开关与此策略约束，静音测试不能证明设备故障。

检查日志中的 TTS 加载、合成和播放错误。自动 Kokoro 加载失败可回退 Melo；生成阶段失败继续提示。0.6.0 等最终回复完整生成后才分段朗读，工具前说明只显示文字；首音等待可能比旧版更长。试听清理后的输入最多 240 字符，自动观察最终答复沿用分段合成，不能继续套用旧观察 240 字限制。关闭朗读只影响音频，文字仍应正常回复。

### 记忆或配置没有保留

“记忆”标签单独点击“保存记忆”；控制中心关闭自动保存与托盘完全退出是不同路径，退出前先保存草稿。看状态是否“配置已保存”，失败时窗口保留，不能当成成功。

确认是同一个源码/安装目录：各自 `data/` 相互独立，不自动迁移。配置 JSON 损坏会保留原文件并整份使用默认值；记忆 JSON 损坏读作空记忆。备份原文件后按正确格式修正，再保存。

记忆总量、单条和敏感内容限制见 [配置与数据](配置与数据.md#记忆限制)。提示要求授权含糊时先询问，实际模型仍可能误判；先在“记忆”标签核对实际内容，不能只依据回复声称的结果。0.6.0 通过工具按需检索与保存，不再每轮强制读取记忆或另起固定授权分类。

### 观察或动作判断不符合预期

0.6.0 不按“无需回应”等正文关键词隐藏内容；观察通过结束工具保持安静，模型若仍输出文字会原样显示。模型仍可能误判画面或操作意图，纯英文回复也可能沿用 fast。遇到问题先核对实际动作、记忆和语音状态，再提供原话及复现步骤；已知差异和历史结果见[候选验收记录](../归档/对话与记忆/验收/模型自主工具对话候选验收-2026-10-16.md)。

### 形象、预览与屏幕位置

- 白底或棋盘仍可见：源文件需有真实透明通道；导入器不自动抠图。
- 导入拒绝：核对文件大小、帧数、像素上限、透明度和是否 UNC 路径，详见 [形象限制](#形象与预览)。
- 预览仍显示旧上下跳动且没有眨眼按钮：核对 `release.json` 是否 0.5.4 或更新，并退出旧进程再启新版；0.5.3 及以前没有该预览。
- 显示“动态预览暂不可用”：查看 Live2D/OpenGL 错误，切到其他标签后再返回“桌宠形象”重试；静态回退能显示不等于动态模型加载成功。
- 导入图片没有眨眼/口型：自定义图片不自动获得 Live2D 绑定；预览也不接 TTS 口型。
- 多屏附图读错位置：手动及语音附图使用最近有效外部鼠标事件位置，本应用内操作或仅移动不立即更新；在目标外部窗口操作后再提问。
- 角色突然隐藏：核对是否全屏或桌面不可用；恢复桌面后显示，连续对话可能需重新开启。休眠本身显示闭眼角色，不隐藏窗口。

### 控制入口与上传状态

当前源码的托盘只有“打开控制中心”“休眠/唤醒”“退出”；配置、形象、官网资源、上传和日志都在同一控制窗口的横向标签栏内。标签被挤出时，使用左右滚动按钮，也可用 `Ctrl+Tab` / `Ctrl+Shift+Tab` 循环切换。全局快捷键不可用时先从托盘打开，在“模型设置”修改后保存。若仍看到独立快捷聊天或旧菜单，先确认运行目录，退出旧进程后再启动更新后的源码；核对该目录 `release.json` 的版本、源码提交与渠道；版本仍为 0.6.0 时也不能仅凭版本号判定当前源码是否已同步。

收起控制中心不会取消上传。需要停止任务时切回“模型上传”标签，点击“取消操作”；提示已有任务时先等待或取消。显示“完成加入资源库”表示上传版本已保留，可在相同站点和原账号下重试入库；完整退出后从官网“我的资源”查看已上传版本。详见 [官网资源上传](#官网资源与本地上传)。

### 诊断与报告

提供版本、入口目录类别（源码/安装版）、触发步骤、界面状态和相关错误片段即可。分享前去除本机路径和个人资料；不要上传整个 `data/`，其中包含设置、记忆和导入图片。

“运行日志”标签只读取当前文件尾部，较早记录可查看轮转备份。普通日志不保存聊天历史；需要重现模型或窗口问题时，使用 [开发与验证](../项目/CONTRIBUTING.md) 中的对应工具，并保留新的报告名。历史测量和验收只是特定条件的证据，不保证当前设备的体验。
