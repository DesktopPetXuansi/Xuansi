# 形象与模型历史

2026-10-19 按当前源码核对。历史功能是本轮源码新增能力，尚未纳入公开 0.7.1 安装包；网页模块见 [个人空间与历史](../官网/个人空间与历史.md)，证据与未验收范围见 [本轮验收](../官网/验收/个人空间与历史-2026-10-19.md)。

## 找回使用过的形象

在控制中心打开 **更换形象 → 使用历史**，选择一条记录并点击 **预览这个形象**。预览满意后，仍需点击 **使用这个形象** 才会切换并保存。默认形象、图片、动图和已安装模型均沿用同一成功事务；旧“更多资源”入口选择的形象也经过该流程。

最多保留最近 **100 条**成功使用记录。只有选择已保存、真实桌宠试载成功后才记录；导入、下载、预览、保存失败和试载回滚不计成功。文件丢失或损坏时提示重新导入或下载，不以失效记录冒充恢复完成。移除或清空记录只删除历史，不删除形象文件，也不改变当前形象。

## 回选 AI 模型配置

在 **模型设置 → 配置历史** 选择记录，再点击 **填入配置草稿**。最多保留最近 **20 条**保存成功的 AI 配置，包含对应本机模型及投影文件路径；相同配置重复保存会去重。修改其他设置不会新增模型配置历史。

回选只填写草稿，不立即切换运行中的模型。旧验证证据会清除，需要重新检查连接和能力，再按原流程保存设置。若凭据引用已失效或不再匹配接口，界面提示重新填写 API 密钥。

密钥正文留在 Windows 凭据管理器，历史文件仅保留本机 `credential_ref` 引用。模型配置历史不上传网站；移除、清空或淘汰历史不会删除系统凭据，凭据仍按既有配置保存流程管理。

## 主动开启形象历史同步

在形象历史窗口点击 **连接账号并开启同步**，按浏览器提示登录并同意历史权限。使用“更多资源”中配置的官网地址；上传授权和历史授权相互独立，重新连接或扩权时保留已获得的相应权限。

同步默认关闭。开启后只同步此后新产生的成功使用记录，不补传旧记录；同步同时绑定官网 URL 与账号 ID。换站点或换账号后，原绑定的待同步记录不会发给新账号。失败保留本机记录，可点击 **重试同步**，网络错误不会撤销已经成功的形象切换。

点击 **关闭同步** 后停止后续发送，等待中的开启授权也会作废；已发出的请求可能已由服务器处理，网站已有记录不会自动删除。本机历史继续保存。需要删除网站记录时，到网页 **我的桌宠 → 使用历史** 操作。

## 数据与模块边界

本机数据目录下分别保存 `appearance-history.json` 和 `model-history.json`，各自有条数上限；读取拒绝超过 2MiB 的文件。写入采用同路径锁、独立临时文件和原子替换；损坏文件原样保留并提示，不自动覆盖。源码版和安装版沿用各自数据目录，不自动互迁。

| 模块 | 职责 |
| --- | --- |
| [personal_history.py](../../pet/personal_history.py) | 形象记录、恢复候选、同步绑定及最小正文白名单。 |
| [model_history.py](../../pet/model_history.py) | 模型快照、去重、凭据引用检查和清验证后的草稿。 |
| [history_storage.py](../../pet/history_storage.py) | 有界 JSON、并发锁、损坏保留和原子写入。 |
| [history_tasks.py](../../pet/history_tasks.py)、[history_dialog.py](../../pet/history_dialog.py) | 串行后台磁盘任务、列表操作及主线程结果回执。 |
| [history_sync.py](../../pet/history_sync.py) | 核验当前账号、逐条检查绑定与开关、幂等发送和成功标记。 |
| [history_controller.py](../../pet/history_controller.py) | 连接成功信号、历史入口及草稿回选；同步复用官网任务的取消与退出等待。 |

普通形象更换和模型配置操作见 [使用指南](使用指南.md)；云端字段与权限见 [接口约定](../官网/接口约定.md)。
