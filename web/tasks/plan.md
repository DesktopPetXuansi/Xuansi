# 官网与资源平台实施计划

2026-10-12，用户已确认官网规划并要求参考既定系统执行。当前执行范围为本地实现、测试和客户端接入；外部发布仍按原方案的部署阶段处理。

依据：[官网规划](../docs/官网规划.md)、[接口约定](../contracts/接口约定.md)、[设计规范](../DESIGN.md)。任务以本目录 todo.md 为唯一清单，不改动客户端已有 tasks/ 计划。

采用契约先行的增量开发。网站、Go API 和客户端按文件责任并行，集成验证依赖顺序为数据库与服务 → 账号 → 资源上传校验 → 浏览器工作台 → 客户端下载/安装/应用。

根代理负责接口、部署、数据库运行环境、端到端验收和整合；执行代理分别负责 web/backend、web/frontend 与客户端资源适配。共享文件变更先协调，不覆盖他人修改。

技术实现采用已批准的 React/Next、Go/chi、GORM/PostgreSQL/Goose、S3/本地存储。网站预览首期为封面；本地客户端加载真实 Live2D，发行许可不以本地测试替代。后续商店、公开用户分享和自动升级不在首期实现范围。

每项逻辑改动先验证相关测试，再运行类型、构建与集成检查。最终证据保存在 docs/开发验收.md，剩余缺口如实列出。
