## 0.6.0 候选 — 2026-10-16（未发布，验证中）

- 合并已提交的统一控制中心、横向标签、官网资源接入与客户端直接上传能力；具体界面增量保留在下方 2026-10-15 原阶段记录，本节不将其改写为已发布。
- 将用户原话、上下文和工具说明交给模型，由模型直接回答或按需调用截图、记忆、朗读、引擎和角色动作工具；执行真实结果回传后继续回答，移除固定前置控制分类与独立保存授权复核阶段。
- 自动观察改用独立结束工具，移除“输出无需回应再过滤”的约定。无正文时安静结束；原生正文与独占结束工具并存时保留正文并结束，避免强制重试产生重复提醒。模型正文、引用、括号及首尾空白均不按关键词删除。
- 每次原生响应收齐后显示正文，工具过程说明保留但不朗读；最终答复完整生成后按实际开关与本轮引擎分段合成。旧版生成与首音重叠的耗时不能当作候选保证。
- 工具调用和成功、失败、取消或未知结果进入会话历史；已开始的记忆写入取消后仍等到终态。Qt 动作使用唯一请求 ID 与执行前检查，等待末帧参数写入、Update 和 Draw 全部成功才确认完成；异常清除待完成状态并回传 unknown，防止后续普通帧误报完成。
- 用户原话独立保留为 user 消息，程序明确捕获的附图与观察图放在真实预完成 capture_screen 工具资料回执，避免图中文字继承操作授权。提示限定保存、朗读开关与动作三类状态改变须经本轮明确请求，读工具、本轮 TTS 和观察结束由模型自主选择；关闭声音仍可文字回复。
- 带工具的单次原生请求增加明确 1024 token 内部思考预算，另留结束标记额度，容量检查按真实总生成额度计算；保持直接对话与原生工具选择，不恢复前置分类。
- 更新原生工具回归与真实模型验证入口，旧模型验收脚本转向新 suite，另存报告；ASR、轻声、旧 NPZ 重放和实际合成波形不因此视为重新通过。使用及执行边界见 [模型自主工具对话](../对话与记忆/模型自主工具对话.md) 和 [开发与验证](CONTRIBUTING.md)。

验证状态：主代理最新完整 pytest 为 500 passed、2 skipped，Ruff 通过。真实 Qt 动作完成与中断、绘制异常和观察终结均经定向检查及独立复核。4B 对比 full 为 119 项／10 失败；9B 主体保真 full 为 119 项／1 失败，14 项记忆关系经人工核对。修复重复提醒后，33 项观察及 22 项新表达通过；语音 6 项仍有 1 项纯英文沿用 fast 的失败。独立十轮性能诊断通过，首波形中位 1.885 秒，播放端为模拟接收器。全部历史失败、人工发现、分组复验与测量边界保留在[候选验收记录](../对话与记忆/验收/模型自主工具对话候选验收-2026-10-16.md)。用户目前只批准更大模型实验，默认仍为 4B；默认选择、安装及发行待后续完成。

此前 25 项请求范围／内部思考诊断：无思考 12 失败、512 token 3 失败、1024 token 0 失败。该局部改善不覆盖后续完整矩阵的实际失败。

## 0.3.0 — 2026-09-29

### 新增

- 默认玄司切换为 Live2D，支持自动眨眼、鼠标视线跟随和休眠闭眼；朗读口型跟随实际播放音量。

## 0.2.0 — 2026-09-25

### 新增

- 模型结合用户意图和上下文自动关闭或恢复朗读，支持文字和已开启的语音对话；静音保留麦克风，恢复当轮即可朗读，主面板与快捷窗口同步显示状态。

## 0.1.0 — 2026-09-20

### 新增

- 首个 Windows 11 x64 在线安装包，内置 Python 3.13.15，安装时下载依赖和模型。

### 已有功能

### 当前限制

- 需要兼容 CUDA 12.4 的 NVIDIA GPU；模型路径固定为 `D:\AI\Models\desktop-pet`。

- 卸载保留用户数据、安装后下载的运行环境和模型。
