# 模块复用边界收敛

日期：2026-10-18。用户已同意先检查、再按检查结果修改。本轮只收敛安装计划规则与推理路由的依赖边界，不改变功能范围，也不新增真实 API 调用。

状态：两项调整已完成，计划与最终实现均经独立复核；全量验证及保留限制见 [本轮验收](../验收/模块复用边界-2026-10-18.md)。

## 检查结论与行为基线

- `scripts/preflight.py:create_plan` 混合了输入转换、设备探测、适配规则、档案验证与空间预算；其他入口复用规则时必须依赖 CLI。
- `pet/ai/selection.py:InferenceRouter` 默认创建具体本地引擎，并读取全局目录、检查模型文件和识别固定备用型号；单独复用路由必须携带这些产品装配知识。
- 当前实际生产入口为 `pet/runtime.py` 与 `scripts/verify_tool_dialogue.py`。不将 UI 与业务编排强行改造成通用组件。
- 修改前定向行为基线：`test_ai_selection`、`test_ai_install`、`test_ai_memory`、`test_ai_providers` 共 **67 passed**。

## 清理计划与具体任务

1. 将计划定稿、能力证明绑定及空间预算提取到共享安装计划模块，接收已有 `InstallPlan`、设备事实与可选档案，不探测、不读凭据、不写文件。CLI 保留输入、探测和输出编排。保留 API 无档案时先生成资源计划、应用配置时再要求完整证明的阶段边界。
2. 将本地资源识别与验证提取为候选解析函数；路由显式接收本地引擎和候选解析器，不自行决定模型目录、备用型号或创建引擎。产品装配入口集中创建这些依赖，并供运行时和验收脚本共同调用。
3. 每片先补有意义的行为回归，修改后运行定向验证。独立审查计划与最终实现，完成全量测试、Ruff、编译和依赖边界检查，再更新验收记录。项目未配置独立静态类型检查器，编译不等同于类型检查。

复用现有契约和工具，不新增依赖、通用容器或重复配置对象。保留其他人的未提交变更；本轮不自动提交或构建正式安装包。

## 回退路径盘点

| 路径 | 分类 | 本轮处理 |
| --- | --- | --- |
| 已存在的旧 D 盘目录继续使用 | 有依据的兼容路径 | 原样保留，目录默认值只在产品装配或输入层决定 |
| 卷身份或空间未知时保留事实并告警，不伪造空间不足 | 有依据的安全降级 | 迁移原规则及同卷、异卷、未知卷回归 |
| API 资源草案暂不要求档案，应用配置时严格验证 | 有依据的阶段兼容 | 保留验证时机，不放宽最终配置门槛 |
| 仅资源错误、未提交响应时切换一次候选，取消／鉴权／额度／协议错误不重试 | 有依据的故障恢复 | 原样保留，锁定测试 |
| 云端优先时仅已验证 CUDA 标准文件可作隐式本地备用 | 有依据的安全边界 | 验证移到本地候选模块，路由保留资格过滤 |
| 4B 验证失败，不能自动进入备用链 | 有依据的能力门槛 | 原样保留，不借重构扩大候选支持范围 |
| 路由内部隐式创建引擎、读取全局路径和固定型号 | 依赖边界问题 | 改为显式注入；不是运行失败后的回退，不增加替代分支 |

未发现需通过吞异常或静默默认值隐藏的失败；不新增此类路径。UI／视觉清理不在本轮范围。完整交付仍受既有 T11 的 CPU／跨设备、其他云端及正式安装实测缺口约束。

## 验收标准

- 安装计划规则可直接接受合成设备报告调用，结果及错误与现有 CLI 一致；保存事务保持原样。
- 路由可使用注入的替身引擎和任意本地候选工作，不依赖产品目录或模型文件；生产装配保持现有候选顺序、显示名、授权、冷却、取消与不重放行为。
- 现有回归与新增边界测试通过；没有真实付费接口调用、密钥读取或内置凭据。
- 最终独立审查及实测结果另记验收页，不能将本轮结构重构表述为全部产品验收完成。
