# 玄司 Xuansi · 本地 AI 桌宠

运行在 Windows 上的本地桌面 AI 伙伴，支持屏幕理解、聊天、语音、长期记忆与 Live2D 形象。

**0.6.0 候选验证中，公开安装包仍为 0.5.6。** 候选源码合并统一控制中心、官网资源接入与原生工具对话，真实模型语义验收仍有失败项；发布前状态见 [更新记录](omx_wiki/项目/CHANGELOG.md)，各轮证据见 [候选验收](omx_wiki/对话与记忆/验收/模型自主工具对话候选验收-2026-10-16.md)。
